# 지인에게 UDID 받기 — 첫 배포 전

Firebase 그룹 초대 링크에 가입해 **가입 완료**가 떠도 UDID가 등록된 것은 아니다.
첫 출시 버전이 없는 현재 상태에서 기기 정보까지 먼저 받으려면 아래 별도 경로를 선택할 수 있다.

## 지인에게 전달할 안내

영민이 iOS 테스트에 쓸 기기를 미리 등록하려고 해요. 설치할 iPhone 또는 iPad에서 진행해 주세요.

1. **Safari**에서 [UDID Tools](https://www.udid.tools/)를 열어요. 카카오톡 안 브라우저라면 Safari로 다시 열어요.
2. **Get iPhone UDID / Get UDID**를 누르고 구성 프로파일 다운로드를 허용해요.
3. 설정 → **프로파일이 다운로드됨**을 열어요. 보이지 않으면 일반 → VPN 및 기기 관리에서 확인해요.
4. 요청 정보와 프로파일 설명을 읽고 동의하면 설치해요. 기기 암호는 기기 화면에만 입력해요.
5. Safari 결과 화면에서 **UDID만 복사**해 개발자에게 개인 메시지로 보내요.
   보내는 형식: `이름(별명) / 기기 이름 / UDID`.
6. 사용이 끝난 프로파일이 설정에 남아 있으면 제거해도 돼요. 앱 설치 안내는 개발자가 별도로 보내요.

이 방법은 제3자 서비스예요. 서비스 안내에 따르면 UDID 외에도 기종·OS·일련번호·IMEI·MEID를 요청해요.
정보 제공에 동의할 때만 사용해 주세요. 결과 링크와 전체 화면 캡처는 보내지 말고 UDID만 보내 주세요.
Apple ID, 학교 계정, Apple Developer 가입이나 PC 연결은 필요 없어요.
학교·회사 관리 기기에서 설치가 제한되면 제한을 우회하지 말고 개발자에게 알려 주세요.

## 개발자가 할 일

- 전달받은 UDID를 Apple Developer → Devices에 등록한다. 테스터 이메일과 UDID는 서로 다른 정보다.
- 앱 본체·위젯·공유 확장의 **세 Ad Hoc 프로파일 모두** 같은 기기 목록으로 다시 생성한다.
- 세 GitHub 프로파일 Secret을 교체하고 서명 빌드를 다시 실행한다.
- 본인 기기 로그인 확인과 Firebase 배포 설정을 마친 뒤 설치 빌드를 전달한다.
- 새 기기는 UDID만 전달한 직후가 아니라 해당 기기를 포함해 재빌드한 뒤 설치할 수 있다.

이 문서는 서비스의 공개 안내를 확인해 작성했다. 실제 지인 기기의 프로파일 설치·UDID 회신까지 검증한 상태는 아니다.
서비스를 원하지 않으면 PC/Mac의 연결 기기 확인 방법을 사용하거나, 첫 Firebase 출시 후 Firebase 기기 등록을 진행한다.
