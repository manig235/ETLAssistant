# 영민이 개인정보처리방침

시행일: 2026년 11월 25일
버전: 1.3 (iOS 첫 판, 앱 0.3.3)

## 들어가며

"영민이"(이하 "앱")는 서울대학교 eTL(Canvas)을 쓰는 학생을 돕는 무료 오픈소스 iPhone 앱입니다. 서울대학교가 만들거나 운영하는 공식 앱이 아닙니다.

앱을 만든 사람(박영민, 이하 "개발자")은 **서버를 운영하지 않으며, 이용자의 개인정보를 받아 보거나 보관하지 않습니다.** 앱이 만드는 로컬 사본은 이용자의 iPhone에 저장됩니다. 인증정보와 AI 대화에 필요한 내용은 아래 2항에 따라 서울대 eTL·OpenAI 등에 직접 전송되며, 외부 서비스도 자체 방침에 따라 정보를 처리·보관할 수 있습니다. 앱에는 광고, 분석(애널리틱스), 크래시 리포트 수집 도구가 들어 있지 않습니다. 다만 이용자가 iPhone 설정에서 "앱 개발자와 공유"를 켰거나 TestFlight 베타로 앱을 설치한 경우, Apple이 iOS 차원에서 수집한 충돌 보고서와 이용자가 직접 보낸 베타 피드백이 Apple을 거쳐 개발자에게 전달될 수 있습니다(Apple의 방침에 따름).

이 방침은 앱이 iPhone 안에서 어떤 정보를 어떻게 다루는지, 어떤 정보가 어디로 전송되는지를 알려 드리기 위한 것입니다.

## 1. 처리하는 정보와 목적

아래 표는 앱의 로컬 저장과 이용 목적을 설명합니다. 저장 방식에 쓰는 말은 다음과 같습니다.

- **Keychain**: iOS Keychain. "이 기기에서만, 처음 잠금 해제한 뒤" 읽을 수 있게 저장하며, iCloud 키체인으로 동기화되거나 다른 기기로 옮겨지지 않습니다.
- **앱 전용 폴더**: 앱의 Application Support 폴더. 다른 앱과 파일 앱에서 보이지 않고, iCloud 백업·컴퓨터 백업에서 제외되도록 설정되어 있습니다.
- **앱 설정 저장소**: iOS 앱 설정 영역(UserDefaults). 다른 앱에서 보이지 않지만 iCloud 백업·컴퓨터 백업에 포함될 수 있습니다(5항).
- **파일 앱의 영민이 폴더**: 파일 앱 → 나의 iPhone → 영민이 → `etl` 폴더(앱의 Documents 폴더). 이용자가 파일 앱에서 보고 옮기고 지울 수 있으며, iPhone을 컴퓨터에 연결하면 Finder 등의 파일 공유에서도 보입니다. 백업에 포함될 수 있고, 앱을 삭제하면 함께 지워집니다.

캘린더 일정은 앱 밖(iPhone 캘린더)에도 저장됩니다.

- **홈 화면·잠금 화면 위젯**: 위젯에 보일 다가오는 마감(과목명·과제명·마감 시각, 내 마감·시험의 장소)과 이번 주 시간표의 사본을 영민이 앱과 위젯만 읽을 수 있는 공유 폴더(App Group)에 둡니다. 위젯은 iPhone 안에서만 그려지며, 잠금 화면 위젯을 추가하면 잠금 상태에서도 그 내용이 보입니다. 위젯을 지우거나 앱을 삭제하면 사라집니다.
- **"공유 → 영민이"**: 다른 앱에서 영민이로 공유한 파일(최대 5개)과 글은 같은 공유 폴더에 잠시 복사된 뒤 새 대화의 첨부·입력창으로 옮겨지고 공유 폴더에서는 지워집니다. 자동으로 보내지 않으며, 이용자가 보내기를 누를 때만 2항처럼 OpenAI로 전송됩니다.
- **캘린더로 자동 넣기**(설정 → 캘린더 연동, 기본 꺼짐): 켰을 때만 과목명·과제명·마감 시각·eTL 과제 링크(쿼리 없는 주소)·내 마감 메모·시험 장소·준비물을 이용자가 고른 캘린더에 씁니다. 기본 대상인 앱의 "영민이" 캘린더가 iPhone 안의 캘린더면 iPhone 밖으로 나가지 않고, iCloud나 Google 같은 계정 캘린더를 고르면 iPhone의 캘린더 동기화가 그 계정 서버로 보냅니다. 토큰·서명 링크는 넣지 않으며, 끄면 앱이 넣은 일정을 지웁니다. OpenAI 및 캘린더 계정 등 외부 전송·보관은 2항을 함께 확인해 주세요. 개발자는 앱에서 이 정보를 수집하는 서버를 운영하지 않습니다.

앱은 이름, 학번, 전화번호, 위치, 연락처, 광고 식별자 등 기기 식별자를 따로 수집하지 않습니다. ChatGPT로 로그인하면 OpenAI가 알려 준 계정 이메일을 위 표처럼 iPhone에 저장합니다. 또 eTL이나 OpenAI 응답 안에 이용자 이름 등이 들어 있을 수 있고, 그 내용은 위 표에 따른 로컬 사본과, 비서가 해당 정보를 읽었을 때 OpenAI로 전송되는 대화·도구 결과에 포함될 수 있습니다.

## 2. 외부로 전송되는 정보

앱의 인증·eTL 조회·AI 요청은 HTTPS로 해당 서비스와 직접 통신하며 개발자의 서버를 거치지 않습니다. ChatGPT 로그인 때 로그인 회신을 받으려고 iPhone 안(127.0.0.1)에서만 잠깐 여는 수신기는 별도입니다(6항). 각 외부 서비스에는 접속 IP와 요청 처리에 필요한 계정·프로그램 정보도 전달될 수 있습니다.

| 받는 곳 | 보내는 정보 | 언제 |
|---|---|---|
| 서울대 eTL (myetl.snu.ac.kr) | eTL 액세스 토큰, 조회 요청 | 이용자가 비서에게 묻거나, 알림 확인·브리핑을 할 때. eTL 토큰은 이곳에만 보냅니다. 앱은 eTL에 글을 쓰거나 과제를 제출하지 않습니다(게시판을 열 때 eTL이 서명해 준 접속 요청 하나만 예외). |
| 서울대 수강편람 (sugang.snu.ac.kr), 서울대 파일 서버 (shine.snu.ac.kr) | 공개된 과목 코드, 강의계획서 첨부 요청 | 시간표·강의계획서를 불러올 때. 로그인이나 eTL 토큰은 보내지 않습니다. |
| eTL 파일 다운로드가 연결하는 HTTPS 저장소 | 해당 파일의 서명된 다운로드 주소와 요청. eTL 액세스 토큰은 eTL 외부 호스트에 붙이지 않음 | 이용자가 요청한 강의자료·제출 파일 등을 받을 때 |
| OpenAI (auth.openai.com, api.openai.com — 이용자 본인의 ChatGPT 계정 또는 API 키) | 서비스 인증을 위한 ChatGPT 인증 토큰 또는 API 키, ChatGPT 로그인 때 이 설치의 임의 ID와 다시 로그인할 때의 계정 이메일(로그인 안내용), 이용자의 질문, 첨부한 사진·파일, 비서가 이용자를 위해 eTL에서 불러온 정보(과목, 과제, 공지, 성적, 강의자료 내용, 내 마감, 시간표 등), "비서가 캘린더 보고 등록하기"를 켰을 때 비서가 읽은 캘린더 일정(제목·시간·장소·메모), 대화에 필요한 앱 지침, 같은 대화의 이전 내용(비서 내부 대화 기록) | 로그인·계정 확인·모델 목록 조회·인증 갱신·로그아웃(인증 철회) 때 인증 요청이 전송되고, 질문·첨부·조회한 내용은 비서와 대화할 때 전송됩니다. 캘린더 일정은 그 스위치를 켜고 비서가 읽을 때만, 공지 내용은 이용자가 비서에게 요청할 때만(공지 알림 창의 "비서가 공지 읽고 채우기"를 눌러 보낸 요청 포함) 갑니다 |
| 이용자가 고른 캘린더 계정(예: iCloud, Google) | 비서가 이용자 요청과 승인으로 넣거나 고치거나 지운 일정 | "비서가 캘린더 보고 등록하기"를 켜고, 비서가 동기화되는 계정의 캘린더를 바꿨을 때만. 앱이 직접 보내지 않고, iPhone의 캘린더 동기화가 그 계정 서버로 보냅니다. 동기화되지 않는 iPhone 안의 캘린더는 iPhone 밖으로 나가지 않습니다. |

**인증정보 입력 위치.** eTL 토큰과 API 키는 첫 설정·설정의 전용 입력란에 넣어 주세요. 채팅 입력창이나 첨부 파일에 직접 넣은 내용은 AI 입력으로 전송될 수 있습니다.

**OpenAI 요청 방식.** 앱은 OpenAI Responses API 요청에 `store: false`를 넣어 OpenAI에 응답 저장을 요청하지 않습니다. 그래서 이전 대화 맥락은 앱이 iPhone에 보관했다가(1항의 비서 내부 대화 기록) 질문할 때마다 함께 다시 보냅니다. 앱은 OpenAI가 제공하는 웹 검색·코드 실행·커넥터 같은 기본 제공 도구를 요청에 넣지 않고, 앱이 정의한 도구(eTL 조회, 작업 폴더 파일 읽기, 내 일정, 캘린더, PDF 만들기)만 씁니다. 이 설정이 OpenAI 방침에 따른 처리·보관까지 막는다는 뜻은 아닙니다.

**OpenAI로 가는 정보에 대하여.** AI 비서는 앱이 OpenAI Responses API를 직접 호출하는 방식으로 동작하며(별도 프로그램이나 중계 서버 없음), 이용자가 로그인한 **이용자 본인의 ChatGPT 계정(Sign in with ChatGPT) 또는 API 키**로 OpenAI와 직접 통신합니다. 개발자는 이 대화를 보거나 받지 않습니다. OpenAI가 이 정보를 어떻게 처리·보관하는지는 OpenAI의 개인정보처리방침과 이용자 계정 설정(예: 데이터 학습 사용 여부)에 따릅니다: https://openai.com/policies/privacy-policy (ChatGPT 계정), https://platform.openai.com/docs/guides/your-data (API 키 이용). 앱의 요청 설정과 OpenAI의 대화 보관·모델 개선 설정은 별개입니다.
OpenAI는 미국 등 국외에 있으므로, 대화를 하면 위 정보가 국외로 전송됩니다(이전받는 자: OpenAI, 이전 국가: 미국 등, 이전 시기·방법: 대화할 때마다 인터넷으로, 보유기간: OpenAI 방침과 이용자 계정 설정에 따름). 원하지 않으면 AI 비서를 쓰지 않고 알림·일정·시간표 기능만 쓸 수 있습니다.

**이용자가 직접 여는 링크.** 앱 안의 eTL 링크, "eTL 토큰 만들러 가기", 문의(카카오톡 오픈채팅) 같은 버튼은 Safari나 해당 앱(예: LearningX 앱)을 열 뿐이며, 그 뒤의 처리는 각 서비스의 방침에 따릅니다. ChatGPT 로그인은 앱 안의 브라우저 시트(Safari 기반)에서 OpenAI 로그인 페이지를 엽니다. 파일 카드의 "공유"를 누르면 iOS 공유 시트가 열리고, 이용자가 고른 앱(예: Google Drive, 메일)으로 그 파일이 전달되며, 저장과 업로드는 이용자가 고른 앱에서 처리합니다. 앱은 Google Drive 같은 서비스와 직접 통신하거나 로그인하지 않습니다.

## 3. 제3자 제공과 처리 위탁

개발자는 앱 정보를 모아 판매하거나 보관하는 서버를 운영하지 않습니다. 다만 앱은 2항의 기능을 수행할 때 이용자가 연결한 외부 서비스로 인증정보와 필요한 내용을 직접 전송합니다. 외부 서비스는 자체 방침과 이용자 계정 설정에 따라 정보를 처리합니다. 개발자 서버를 거치지 않는다는 사실이 외부 전송이나 외부 서비스의 보관이 없다는 뜻은 아닙니다.

## 4. 보유 기간과 파기

- iPhone 안의 정보는 이용자가 지우거나 앱을 삭제할 때까지 남습니다(Keychain과 백업은 아래와 5항 참고). 첨부·작업 파일은 저장 후 14일이 지나면 정리 대상이 됩니다. 앱이 eTL 파일·강의계획서를 받을 때, 그리고 앱을 열거나 알림 확인을 할 때 하루 한 번까지 정리합니다. 파일 앱의 영민이 폴더 `etl`에 저장한 파일은 이용자가 자동 정리 기간(2·7·30일)을 고른 경우에만 같은 때 정리하며(`영민이가 만든 파일` 폴더 제외), 고르기 전이나 "정리 안 함"이면 지우지 않습니다. 앱을 오래 열지 않거나 iOS가 백그라운드 작업을 미루면 실제 삭제는 다음에 앱이 실행될 때까지 늦어질 수 있습니다. 알림 기록은 최근 90일(최대 300개) 범위로 관리하며 기록을 갱신할 때 오래된 항목을 정리합니다. 진단 로그는 iOS가 정한 기간이 지나면 iOS가 지웁니다.
- 지우는 방법
  - 대화: 대화 목록에서 지우기. 비서 내부 대화 기록도 함께 지웁니다. 삭제한 대화에 첨부된 앱 전용 파일 중 다른 저장된 대화가 참조하지 않는 사본도 지웁니다. 파일 앱의 영민이 폴더나 다른 앱에 저장한 사본은 남으며, 삭제되지 않은 작업 사본은 14일 정리 대상입니다. 내부 대화 기록을 바로 지우지 못하면 다음에 앱을 열 때 다시 지웁니다.
  - eTL 토큰: 설정 → eTL 토큰 → "eTL 연결 해제". 토큰과 함께 앱이 eTL에서 받아 둔 과제 목록, 새 과제·성적 비교 기준, 수강편람 시간표, 강의계획서 첨부, 새 강의자료 비교용 파일 목록, 게시판 접속 토큰을 지웁니다. 대화와 그 안에서 받은 파일, 파일 앱의 영민이 폴더에 저장한 파일, 알림 기록, 내 마감, 직접 넣은 수업·보강/휴강은 남으므로 필요하면 각각 지웁니다.
  - 알림 기록: 알림 기록 화면에서 "기록 지우기"
  - ChatGPT 로그인: 설정 → ChatGPT 계정 → 로그아웃. Keychain의 인증 토큰과 저장한 계정 이메일·계정 ID를 지우고 OpenAI에 인증 철회를 요청합니다. 철회를 확인하지 못하면 앱이 알려 드리며, 이때는 ChatGPT 설정에서 연결을 끊을 수 있습니다.
  - OpenAI API 키: 설정 → OpenAI API 키(고급) → 삭제
  - 내 마감, 보강·휴강: 해당 화면에서 지우기
  - 비서가 캘린더에서 바꾼 일정: 설정 → 캘린더 연동 → "비서가 바꾼 일정"에서 되돌리기(최근 14일). 되돌리기는 알림·초대 정보까지 복원하지는 않습니다. 비서가 넣은 일정은 캘린더 앱에서도 지울 수 있습니다. 캘린더 읽기를 그만두려면 "비서가 캘린더 보고 등록하기"를 끄거나 설정 앱 → 영민이 → 캘린더에서 권한을 거둡니다.
  - 등록 안 한 공지 목록: 시트에서 무시하거나, 설정 → 알림에서 "앱을 열 때 등록할 공지 보여 주기"를 끕니다(최근 14일 항목만 보여 주며, 공지 목록을 갱신할 때 오래된 기록을 정리합니다).
  - 파일 앱의 영민이 폴더 `etl`의 파일(비서가 만든 PDF가 있는 `etl/영민이가 만든 파일` 포함): 파일 앱 → 나의 iPhone → 영민이에서 직접 지우기. 앱을 삭제하면 이 폴더도 함께 지워지므로, 남겨 둘 파일은 앱을 지우기 전에 다른 위치로 옮겨 주세요.
  - 앱 데이터 전부: 설정 앱 → 일반 → iPhone 저장 공간 → 영민이 → 앱 삭제(또는 홈 화면에서 앱 삭제). "앱 정리하기"는 문서와 데이터를 남기므로 지우려면 "앱 삭제"를 고릅니다. iOS는 앱을 삭제해도 Keychain 항목을 기기에 남겨 둘 수 있지만, 앱을 다시 설치하고 처음 실행하면 앱이 남아 있던 Keychain 항목(eTL 토큰·ChatGPT 로그인·API 키)을 먼저 지웁니다. ChatGPT 인증 철회까지 하려면 앱을 삭제하기 전에 로그아웃해 주세요.
- iCloud 백업이나 컴퓨터 백업에 이미 들어간 사본(5항)은 앱이 지울 수 없으므로, 필요하면 해당 백업을 직접 지웁니다.
- OpenAI에 이미 보낸 대화는 개발자가 지울 수 없습니다. ChatGPT/OpenAI 계정에서 관리하거나 OpenAI에 요청해야 합니다.
- eTL 토큰을 더 이상 쓰지 않으려면 eTL(계정 → 설정 → 승인된 통합)에서 그 토큰을 폐기할 수 있습니다.

## 5. 백업

eTL 토큰, ChatGPT 인증 토큰, API 키는 "이 기기에서만" 쓰도록 Keychain에 저장하므로 iCloud 키체인으로 동기화되지 않고 새 iPhone으로 옮겨지지 않습니다. 대화, 비서 내부 대화 기록, 첨부·작업 파일이 있는 앱 전용 폴더는 iCloud 백업과 컴퓨터 백업에서 제외되도록 설정되어 있습니다. 그래서 새 iPhone에서는 eTL 토큰 입력과 ChatGPT 로그인을 다시 해야 하고, 대화는 옮겨지지 않습니다.

다만 앱 설정 저장소에 있는 정보(앱 설정, 내 마감, 시간표·보강/휴강, eTL 정보 사본, 등록 안 한 공지 목록, 알림 기록, 고른 캘린더와 되돌리기 기록, ChatGPT 계정 이메일 등)와 파일 앱의 영민이 폴더 `etl`의 파일은 백업에서 제외되지 않습니다. 이용자가 iCloud 백업이나 컴퓨터 백업을 켜 두었다면 이 정보가 iOS 백업에 포함되고, 백업에서 복원한 iPhone으로 옮겨질 수 있습니다. 이 백업은 Apple(iCloud) 또는 이용자의 컴퓨터에 이용자의 설정에 따라 저장되며 개발자에게 전달되지 않습니다.

## 6. 안전성 확보 조치

- eTL 토큰, API 키, ChatGPT 로그인 정보는 iOS Keychain에 "이 기기에서만, 처음 잠금 해제한 뒤" 읽을 수 있게 저장하고, 로그·오류 메시지에 남기지 않도록 처리합니다. 인증·통신 중에는 필요한 토큰이 앱 메모리에 존재합니다.
- eTL 토큰은 서울대 eTL(myetl.snu.ac.kr)에만 보냅니다. 다른 호스트로 넘어가는 다운로드에는 토큰을 붙이지 않고, eTL·OpenAI 통신에 쿠키를 저장하지 않습니다.
- 비서의 도구는 앱 안에서 실행되며, 앱은 비서를 위한 서버나 네트워크 수신 포트를 열지 않습니다.
- ChatGPT 로그인은 PKCE 방식을 쓰며, 로그인 회신을 받는 수신기는 iPhone 안(127.0.0.1)에서만 접속을 받고, 로그인 시도마다 새로 만든 확인값이 맞는 회신 하나만 받은 뒤 닫힙니다(취소하거나 15분이 지나도 닫힘). 로그인 브라우저 시트는 쿠키를 남기지 않는 임시 세션으로 엽니다.
- 비서는 eTL을 읽기만 합니다. 내 마감·보강·휴강 및 허용한 캘린더의 추가·수정·삭제는 변경 내용을 보여 주는 앱 확인 창에서 이용자가 승인해야 실행합니다. 취소·시간 초과·화면 이탈 시 대기 중인 변경을 거절합니다. 반복 일정과 다른 사람이 초대된 일정은 비서가 고치거나 지우지 않습니다. 캘린더 계정의 일정은 계정 동기화로 외부 서버에도 반영될 수 있습니다.
- 비서에게는 앱이 정의한 도구만 주며(웹 검색·코드 실행·메일 등 커넥터 없음), 파일·이미지 읽기 도구의 경로를 앱 작업 폴더로 제한합니다. 이미지 도구는 위치정보 등 원본 메타데이터를 제외하고 이미지를 다시 인코딩합니다. 도구 결과에서 알려진 토큰·서명 링크를 가립니다. 이용자가 이미지나 문서 본문에 적어 첨부한 비밀정보까지 자동으로 식별·제거하는 기능은 아닙니다.
- 앱 소스 코드는 공개되어 있어 누구나 위 내용을 확인할 수 있습니다: https://github.com/manig235/ETLAssistant

## 7. 이용자의 권리

이용자는 언제든 4항의 방법으로 iPhone 안의 정보를 보고, 고치고, 지울 수 있고, eTL 연결·ChatGPT 로그인·알림·백그라운드 앱 새로 고침을 끌 수 있습니다. 개발자는 이용자 정보를 갖고 있지 않으므로 개발자에게 열람·삭제를 요청할 정보는 없습니다. OpenAI에 보낸 정보는 OpenAI에, eTL 정보는 서울대학교에 요청할 수 있습니다.

## 가상 eTL 테스트 모드

학교 계정 없이 앱을 시험할 수 있도록 가상 과목·과제·공지·강의자료를 앱 안에서 제공합니다. 가상 모드에서는 실제 eTL·LearningX·수강편람에 연결하지 않으며 실제 eTL 토큰도 사용하거나 변경하지 않습니다. 가상 대화·파일·내 일정·알림 설정은 실제 모드와 별도로 저장합니다. 실제 캘린더·위젯 연결은 가상 모드에서 사용하지 않습니다.

가상 모드의 채팅도 사용자가 로그인한 실제 ChatGPT 또는 API 키를 사용합니다. 질문, 첨부 및 AI가 조회한 가상 자료는 답변 생성을 위해 OpenAI로 전달됩니다. ChatGPT 로그인은 두 모드에서 공유되며, 가상 데이터를 초기화해도 로그아웃하지 않습니다. 모드 전환과 가상 데이터 초기화는 설정에서 예약한 다음 앱 실행에 적용됩니다.
