# 홈 화면 위젯

위젯 선택기에서 일정 2×2·2×1, 주간 시간표 4×4·4×6, 다음 수업 2×1을 따로 추가한다(크기 추가는 0.2.8). Android 기본
RemoteViews로 구현하며, Codex를 실행하거나 별도 서버로 데이터를 보내지 않는다.

## 일정

- 기본 2×2와 작은 2×1을 제공한다. 개수 상한 없이 실제 높이와 시스템 글자 크기에 들어가는 만큼 표시한다.
  실제 칸의 dp 크기는 런처에 따라 달라진다. 큰 시스템 글꼴에서는 읽을 공간에 맞춰 개수를 줄인다.
- 기간 제한 없이 앞으로 마감인 eTL 과제와 내 마감을 함께 마감순으로 표시한다.
  설정 → 알림 → 과목별 알림에서 숨긴 과목의 과제는 뺀다. 시간표·다음 수업 위젯은 숨긴 과목 중 "시간표·오늘 수업에서도 숨기기"를 켠 과목만 뺀다(`CourseFilter.timetableDay`, 보강·휴강 포함).
  제출·완료, 마감 시각이 지난 항목, 마감이 없는 항목은 제외한다.
- 제목, 마감 날짜·시각, 남은 시간을 표시한다. 2×1은 헤더 없이 두 줄로 압축한다. 긴 글은 줄임표로 줄인다.
- 위젯 제목은 개수 없이 `일정`으로 표시하며 설정·런처의 이름도 일정으로 통일한다.
- 본문은 큰 글자로 비교 중이며, 확대에 맞춰 행 높이·표시 개수도 조정해 마지막 항목이 잘리지 않게 한다(0.2.8).
- 항목 사이에 구분선을 두고, 둥근 모서리에서 제목이 잘리지 않도록 왼쪽·위 안쪽 여백을 둔다.
- 과제는 해당 eTL HTTPS 링크를 연다. 연결 가능한 앱이나 브라우저 선택은 기기 설정을 따른다.
- 내 마감 본문은 앱의 해당 마감 수정 창을 열고, 원형 완료 버튼은 완료 상태를 저장한다.
  연속으로 눌러도 미완료로 되돌리지 않는다. 헤더를 누르면 내 일정 전체를 연다.
- 설정 → 기타 → 홈 화면에 위젯 추가하기에서 다섯 가지 종류 중 선택하면 시스템의 추가 확인 창을 요청한다.
  런처가 직접 추가를 지원하지 않으면 홈 화면의 위젯 목록에서 추가하는 방법을 안내한다.

## 시간표

- 주간 격자는 4×4·4×6칸을 제공한다. 누르면 앱의 시간표 화면을 연다.
- 시간표 제목과 수업 블록의 텍스트는 가운데 정렬하며, 블록 글자는 11 기준으로 확대하고 자간·줄 간격을 늘린다.
- 다음 수업 위젯도 두 줄을 가운데 정렬한다.
- 보이는 헤더는 시간표·요일만 표시하고 날짜 범위와 월/일은 생략한다.
- KST 기준 이번 주 월~일을 사용하며, 수업이 있으면 주말 열도 표시한다.
- 수강편람 수업과 직접 등록한 반복 수업을 함께 표시한다.
  앱에 등록한 이번 주 휴강·보강을 반영하고, 휴강은 흐린 블록과 `휴강` 문구로 남긴다.
- 겹치는 수업은 열을 나눠 표시한다. 빈 시간표는 앱으로 이동하는 안내를 표시한다.
- 격자는 기기에서 그린 비트맵 하나로 전달하고 매번 전체 RemoteViews를 교체한다.
  접근성 설명에는 날짜·수업 시각·과목·강의실·휴강/보강을 텍스트로 제공한다.

## 다음 수업

- 2×1칸에 과목, 오늘/내일/요일, 시작 시각과 강의실을 표시한다. 미정인 강의실은 생략한다.
- 수업 시작 후 30분까지 해당 수업을 유지하고, 그 시점부터 다음 수업을 표시한다. 30분보다 짧으면 종료 때 전환한다.
- 오늘부터 7일 뒤까지 탐색해 다음 주 수업도 찾으며, 직접 등록·보강을 포함하고 휴강은 제외한다.
- 누르면 앱의 시간표 화면을 연다. 수업을 찾지 못하면 빈 상태를 표시한다.

## 갱신

`SnapshotCache`, `MyDeadlineStore`, `TimetableStore`, `TimetableChangeStore`의 저장 경로에서
위젯 갱신을 예약하므로 UI·AI 도구·기존 알림 조회 결과를 공유한다. 위젯 전용 시간당 조회는
마지막 과제 정보가 한 시간 이내이면 재사용하고, 시간표는 기존 하루 캐시를 따른다.
위젯만 쓸 때도 조회되며 알림 권한이나 알림 활성화 여부에 의존하지 않는다.
이 조회는 알림을 발송하거나 알림 중복 기록/공지 기준선을 변경하지 않는다.

남은 시간은 네트워크 없이 15분 주기로 다시 계산한다. 다음 마감·다음 수업 전환 시각과 KST 자정에도
로컬 표시 갱신을 예약한다. 기기 절전 정책으로 작업이 늦어질 수 있어 실시간 갱신을 보장하지 않는다.
연결 실패 시 기존 정보를 유지하고, 위젯이 모두 제거되면 관련 예약 작업을 취소한다.
재부팅·앱 업데이트·시각 변경 때 예약과 표시를 되살린다. 색상은 시스템 라이트/다크 모드를 따른다.

## 검증

`WidgetLogicTest`는 기간 제한 없는 통합 정렬, 제출·완료·지난 마감 제외, 링크 제한,
크기/글꼴별 개수, KST 마감 경계, 주 전환, 커스텀 수업, 휴강·보강, 겹치는 수업, 다음 수업 30분/조기 종료 경계를 검사한다.
글자 확대 이전에 SM-S938N의 별도 테스트 패키지에서 합성 자료로 실제 RemoteViews를 적용해 최소 크기의
마감 두 항목·구분선·헤더 여백, 두 소형 위젯, 큰 주간 시간표의 날짜 생략을 확인했다.
개인 계정·일정 데이터는 쓰지 않았다. 최종 실제 앱에서도 다섯 선택지와 새 세 종류의 삼성 홈
추가 확인 창을 확인하고 취소했다. 임시 테스트 앱은 제거했다. 실제 런처에서 다음 동작은 별도로 확인해야 한다.

1. 다섯 종류 위젯 추가, 세로·가로 크기 변경, 여러 인스턴스와 시스템 큰 글꼴.
2. eTL 링크 이동, 내 마감 수정 창 이동, 완료 버튼 연속 입력 및 목록 갱신.
3. 휴강/보강 수정, 월요일 전환, 주말 수업 및 빈 시간표.
4. 알림을 끈 상태의 자동 조회, 연결 실패 시 기존 정보 유지, 재부팅 및 위젯 전체 제거.
