# 영민이 개인정보처리방침

시행일: 2026년 11월 28일
버전: 1.4

## 들어가며

"영민이"(이하 "앱")는 서울대학교 eTL(Canvas)을 쓰는 학생을 돕는 무료 오픈소스 안드로이드 앱입니다. 서울대학교가 만들거나 운영하는 공식 앱이 아닙니다.

앱을 만든 사람(박영민, 이하 "개발자")은 **서버를 운영하지 않으며, 이용자의 개인정보를 받아 보거나 보관하지 않습니다.** 앱이 만드는 로컬 사본은 이용자의 휴대폰에 저장됩니다. 인증정보와 AI 대화에 필요한 내용은 아래 2항에 따라 서울대 eTL·OpenAI 등에 직접 전송되며, 외부 서비스도 자체 방침에 따라 정보를 처리·보관할 수 있습니다. 앱에는 광고, 분석(애널리틱스), 크래시 리포트 수집 도구가 들어 있지 않습니다.

이 방침은 앱이 휴대폰 안에서 어떤 정보를 어떻게 다루는지, 어떤 정보가 어디로 전송되는지를 알려 드리기 위한 것입니다.

## 1. 처리하는 정보와 목적

아래 표는 앱의 로컬 저장과 이용 목적을 설명합니다. 다운로드 파일과 캘린더 일정은 앱 전용 저장공간 밖에도 저장됩니다. OpenAI 및 캘린더 계정 등 외부 전송·보관은 2항을 함께 확인해 주세요. 개발자는 앱에서 이 정보를 수집하는 서버를 운영하지 않습니다.

앱은 이름, 학번, 이메일, 전화번호, 위치, 연락처, 기기 식별자를 따로 수집하지 않습니다. 다만 eTL이나 OpenAI 응답 안에 이용자 이름 등이 들어 있을 수 있고, 그 내용은 위 표에 따른 로컬 사본과, 비서가 해당 정보를 읽었을 때 OpenAI로 전송되는 대화·도구 결과에 포함될 수 있습니다.

## 2. 외부로 전송되는 정보

앱의 인증·eTL 조회·AI 요청·업데이트 확인·공개 기출 자료 찾기는 HTTPS로 해당 서비스와 직접 통신하며 개발자의 서버를 거치지 않습니다. 휴대폰 안에서 앱과 Codex가 통신하는 인증된 로컬 HTTP와 프로세스 간 파이프는 별도입니다. code-mode 실행에는 네트워크 수신 포트를 열지 않습니다. 각 외부 서비스에는 접속 IP와 요청 처리에 필요한 계정·프로그램 정보도 전달될 수 있습니다.

| 받는 곳 | 보내는 정보 | 언제 |
|---|---|---|
| 서울대 eTL (myetl.snu.ac.kr) | eTL 액세스 토큰, 조회 요청 | 이용자가 비서에게 묻거나, 알림 확인·브리핑을 할 때. eTL 토큰은 이곳에만 보냅니다. 앱은 eTL에 글을 쓰거나 과제를 제출하지 않습니다(게시판을 열 때 eTL이 서명해 준 접속 요청, 그리고 이용자가 "서울대 로그인으로 연결"을 눌러 로그인했을 때 토큰을 하나 만드는 요청만 예외). |

| 이용자가 고른 캘린더 계정(예: Google, 삼성) | 캘린더에 넣은 일정(1항), 비서가 이용자 요청으로 넣거나 고친 일정 | 자동으로 넣기를 켜고 동기화되는 계정의 캘린더를 골랐을 때, 또는 비서가 그런 캘린더에 일정을 넣었을 때만. 앱이 직접 보내지 않고, 휴대폰의 캘린더 동기화가 그 계정 서버로 보냅니다. 기본 대상인 "영민이" 캘린더는 휴대폰 밖으로 나가지 않습니다. eTL 토큰이나 서명 링크는 일정에 넣지 않습니다. |
| GitHub (api.github.com) | 새 버전 확인 요청(앱이 개인정보·토큰·기기 식별자를 첨부하지 않음, 접속 IP는 GitHub에 전달됨) | 하루 한 번 예약 작업, 채팅 화면을 열 때 마지막 확인에서 6시간 이상 지났으면 확인, 또는 이용자의 수동 확인. 설정 "업데이트 알림"에서 자동 확인을 끌 수 있습니다. |

**서울대 로그인으로 연결.** 첫 실행 안내나 설정에서 "서울대 로그인으로 연결"을 누르면 서울대 로그인 페이지가 앱 안 화면에 열립니다. 로그인은 서울대 페이지에서 이루어지고, 앱은 아이디·비밀번호를 읽거나 저장하지 않습니다(서울대 밖 주소는 이 화면에서 열지 않고 브라우저로 넘깁니다). 로그인이 끝나 eTL 화면으로 돌아오면 앱이 그 로그인 상태로 이용자의 eTL 계정에 "영민이 (기기 모델명)"이라는 이름의 액세스 토큰을 하나 만들고(eTL의 토큰 만들기 주소로 요청을 하나 보냅니다. eTL이 그 주소를 지원하지 않으면, eTL 웹 설정의 "새 액세스 토큰" 버튼이 쓰는 주소로 한 번 더 보냅니다. 토큰은 하나만 만들어집니다), 확인한 뒤 위 1항처럼 암호화해 저장합니다. 이 화면의 쿠키·웹 저장소·캐시·방문 기록은 연결이 끝나거나 실패하거나 화면을 닫으면 바로 지우며, 도중에 앱이 강제로 종료되었으면 다음 실행 때 지웁니다. 만든 토큰은 eTL 설정의 승인된 통합 목록에 보이고, 언제든 그곳에서 폐기할 수 있습니다.

**인증정보 입력 위치.** eTL 토큰과 API 키는 첫 설정·설정의 전용 입력란에 넣어 주세요. 채팅 입력창이나 첨부 파일에 직접 넣은 내용은 AI 입력으로 전송될 수 있습니다.

**Codex 사용 통계.** 앱은 Codex 설정에서 OpenAI로 보내는 사용 통계(analytics)·지표 내보내기·피드백 수집을 꺼 둡니다(`[analytics] enabled = false`, `[otel] metrics_exporter = "none"`, `[feedback] enabled = false`). 대화에 필요한 요청(질문과 비서의 도구 결과 등)은 위 표대로 OpenAI로 갑니다.

**OpenAI로 가는 정보에 대하여.** AI 비서는 OpenAI의 공식 Codex 프로그램을 휴대폰 안에서 실행하며, 이용자가 로그인한 **이용자 본인의 ChatGPT 계정(또는 API 키)**으로 OpenAI와 직접 통신합니다. 개발자는 이 대화를 보거나 받지 않습니다. OpenAI가 이 정보를 어떻게 처리·보관하는지는 OpenAI의 개인정보처리방침과 이용자 계정 설정(예: 데이터 학습 사용 여부)에 따릅니다: https://openai.com/policies/privacy-policy (ChatGPT 계정), https://platform.openai.com/docs/guides/your-data (API 키 이용). 앱이 사용 통계를 끄는 것과 OpenAI의 대화 보관·모델 개선 설정은 별개입니다.
OpenAI는 미국 등 국외에 있으므로, 대화를 하면 위 정보가 국외로 전송됩니다(이전받는 자: OpenAI, 이전 국가: 미국 등, 이전 시기·방법: 대화할 때마다 인터넷으로, 보유기간: OpenAI 방침과 이용자 계정 설정에 따름). 원하지 않으면 AI 비서를 쓰지 않고 알림·일정·시간표 기능만 쓸 수 있습니다.

**이용자가 직접 여는 링크.** 앱 안의 eTL 링크, 업데이트 받기, 문의(카카오톡 오픈채팅) 같은 버튼은 휴대폰의 브라우저나 해당 앱을 열 뿐이며, 그 뒤의 처리는 각 서비스의 방침에 따릅니다. 파일을 "공유"하거나 "다른 앱으로 열기"를 누르면 이용자가 고른 앱으로 그 파일이 전달됩니다. 다른 앱에서 "공유 → 영민이"로 보낸 파일·글은 새 대화의 첨부와 입력창에 들어갈 뿐 자동으로 보내지지 않으며, 이용자가 보내기를 누르면 다른 첨부와 똑같이 OpenAI로 전송됩니다. 파일 카드 옆 공유 아이콘에서 Google Drive 등 다른 앱을 고르면 해당 앱으로 파일이 전달되며, 저장과 업로드는 이용자가 고른 앱에서 처리합니다. 앱은 Google Drive 같은 서비스와 직접 통신하거나 로그인하지 않습니다.

## 3. 제3자 제공과 처리 위탁

개발자는 앱 정보를 모아 판매하거나 보관하는 서버를 운영하지 않습니다. 다만 앱은 2항의 기능을 수행할 때 이용자가 연결한 외부 서비스로 인증정보와 필요한 내용을 직접 전송합니다. 외부 서비스는 자체 방침과 이용자 계정 설정에 따라 정보를 처리합니다. 개발자 서버를 거치지 않는다는 사실이 외부 전송이나 외부 서비스의 보관이 없다는 뜻은 아닙니다.

## 4. 보유 기간과 파기

- 휴대폰 안의 정보는 이용자가 지우거나 앱을 삭제할 때까지 남습니다. 첨부·작업 파일은 저장 후 14일이 지나면 정리 대상이 됩니다. 앱 프로세스가 시작될 때와 하루 한 번 예약된 작업, 파일을 가져오는 작업에서 정리합니다. 휴대폰이 꺼져 있거나 앱이 강제 중지·절전 제한 상태이면 실제 삭제는 다음 실행 가능한 시점까지 늦어질 수 있습니다. 알림 기록은 최근 90일(최대 300개) 범위로 관리하며 기록을 갱신할 때 오래된 항목을 정리합니다. 진단 로그는 파일 1MB 두 개를 넘으면 오래된 것부터 지웁니다.
- 지우는 방법
  - 대화: 대화 목록에서 지우기. 비서 내부 대화 기록(Codex 세션 기록)도 함께 지웁니다. 삭제한 대화에 첨부된 앱 전용 파일 중 다른 저장된 대화가 참조하지 않는 사본도 지웁니다. 다운로드 폴더나 다른 앱에 저장한 사본은 남으며, 삭제되지 않은 작업 사본은 14일 정리 대상입니다. 비서가 꺼져 있을 때 지운 대화는 기록 파일을 바로 지우고, 남은 내부 색인은 다음에 비서를 켤 때 지웁니다.
  - eTL 토큰: 설정 → eTL 토큰 → "eTL 연결 해제". 토큰과 함께 앱이 eTL에서 받아 둔 과제 목록, 새 과제·성적 비교 기준, 수강편람 시간표, 강의계획서 첨부, 새 강의자료 비교용 파일 목록, 성적 통계(공지에서 읽었거나 직접 넣은 것 포함)를 지웁니다. 캘린더에 이미 넣은 eTL 과제 일정은 지우지 않으므로, 지우려면 설정 → 캘린더 연동에서 자동으로 넣기를 끄세요(로컬 "영민이" 캘린더는 통째로, Google 캘린더는 앱이 추적하는 일정만 지웁니다). 대화와 그 안에서 받은 파일, 알림 기록, 내 마감, 직접 넣은 수업·보강/휴강은 남으므로 필요하면 각각 지웁니다.
  - 알림 기록: 알림 기록 화면에서 지우기
  - ChatGPT 로그인: 설정에서 로그아웃
  - 내 마감, 보강·휴강: 해당 화면에서 지우기
  - 성적 통계: 서랍 → "성적 통계"에서 항목마다 지우기(eTL·공지에서 자동으로 받은 항목은 지운 뒤 다시 받지 않음), 또는 "eTL 연결 해제"로 모두
  - 캘린더에 넣은 일정: 설정 → 캘린더 연동에서 자동으로 넣기 끄기. 로컬 "영민이" 캘린더는 통째로 지워지므로 그 안에 직접 넣은 일정도 삭제됩니다. Google 캘린더는 앱이 추적하는 일정만 지웁니다. 권한이 없거나 삭제에 실패하면 추적 정보를 보존하고 이유를 표시하므로 권한을 복구한 뒤 다시 끄세요. 앱을 먼저 삭제하면 앱이 정리할 수 없으니 캘린더 앱에서 직접 지웁니다.
  - 비서가 캘린더에서 바꾼 일정: 설정 → 캘린더 연동 → "비서가 바꾼 일정"에서 되돌리기. 되돌리기는 알림·초대 정보까지 복원하지는 않습니다. 캘린더 읽기를 그만두려면 두 스위치를 끄거나 휴대폰 설정에서 캘린더 권한을 거둡니다.
  - 등록 안 한 공지 목록: 시트에서 무시하거나, 설정 → 알림에서 "앱을 열 때 등록할 공지 보여 주기"를 끕니다(최근 14일 항목만 보여 주며, 공지 목록을 갱신할 때 오래된 기록을 정리합니다).
  - 휴대폰 `다운로드/etl` 폴더의 파일(비서가 만든 PDF가 있는 `다운로드/etl/영민이가 만든 파일` 포함): 파일 앱에서 직접 지우기(앱을 삭제해도 남습니다)
  - 앱 전용 데이터 전부: 휴대폰 설정 → 애플리케이션 → 영민이 → 저장공간 → 데이터 삭제, 또는 앱 삭제
- OpenAI에 이미 보낸 대화는 개발자가 지울 수 없습니다. ChatGPT/OpenAI 계정에서 관리하거나 OpenAI에 요청해야 합니다.
- eTL 토큰을 더 이상 쓰지 않으려면 eTL(계정 → 설정 → 승인된 통합)에서 그 토큰을 폐기할 수 있습니다. "서울대 로그인으로 연결"로 만든 토큰은 "영민이 (기기 모델명)"이라는 이름으로 보입니다. 앱의 "eTL 연결 해제"는 휴대폰 안의 토큰만 지우고 eTL의 토큰은 지우지 않습니다.

## 5. 백업

앱은 Google 클라우드 백업과 기기 간 이전(새 휴대폰으로 옮기기, 예: 삼성 Smart Switch·Google 기기 이전)에서 앱 데이터를 하나도 내보내지 않도록 설정되어 있습니다. 그래서 새 휴대폰에서는 eTL 토큰 입력과 ChatGPT 로그인을 다시 해야 하고, 대화·내 마감·설정은 옮겨지지 않습니다.

## 6. 안전성 확보 조치

- eTL 토큰, API 키, ChatGPT 로그인 정보는 Android Keystore로 암호화해 저장하고, 로그·오류 메시지에 남기지 않도록 처리합니다. 인증·통신 중에는 필요한 토큰이 프로세스 메모리에 존재합니다.
- eTL 토큰은 서울대 eTL(myetl.snu.ac.kr)에만 보냅니다.
- 비서가 쓰는 eTL 도구는 휴대폰 안(127.0.0.1)에서만 열리고, 실행할 때마다 바뀌는 비밀값이 있어야 쓸 수 있습니다.
- 비서(Codex)의 인터넷 연결을 중계하는 휴대폰 안 프록시(127.0.0.1)도 앱을 켤 때마다 새로 만든 비밀번호가 있어야 쓸 수 있어, 휴대폰의 다른 앱이 이 앱을 거쳐 인터넷에 접속할 수 없습니다.
- 비서는 eTL을 읽기만 합니다. 내 마감·보강·휴강 및 허용한 캘린더의 추가·수정·삭제는 변경 내용을 보여 주는 앱 확인 창에서 이용자가 승인해야 실행합니다. 취소·시간 초과·화면 이탈 시 대기 중인 변경을 거절합니다. 캘린더 계정의 일정은 계정 동기화로 외부 서버에도 반영될 수 있습니다.
- 비서의 일반 셸 실행·외부 웹 검색·메일 등 커넥터를 끄고, 파일·이미지 읽기 도구의 경로를 작업 폴더로 제한합니다. 이미지 도구는 위치정보 등 원본 메타데이터를 제외하고 이미지를 다시 인코딩합니다. 도구 결과에서 인증 필드·알려진 토큰·서명 링크를 가리고 오류 응답의 인증정보가 대화로 전달되지 않도록 제한합니다. 이용자가 이미지나 문서 본문에 적어 첨부한 비밀정보까지 자동으로 식별·제거하는 기능은 아닙니다.
- ChatGPT 계정에 연결된 다른 서비스(메일 등) 도구는 꺼 둡니다.
- 앱 소스 코드는 공개되어 있어 누구나 위 내용을 확인할 수 있습니다: https://github.com/manig235/ETLAssistant

## 7. 이용자의 권리

이용자는 언제든 4항의 방법으로 휴대폰 안의 정보를 보고, 고치고, 지울 수 있고, eTL 연결·ChatGPT 로그인·알림·업데이트 확인을 끌 수 있습니다. 개발자는 이용자 정보를 갖고 있지 않으므로 개발자에게 열람·삭제를 요청할 정보는 없습니다. OpenAI에 보낸 정보는 OpenAI에, eTL 정보는 서울대학교에 요청할 수 있습니다.
