# 영민이 개인정보처리방침 (초안)

> 초안이다. 배포 전에 아래 "공개 전 확인할 것"을 처리하고, 실제 동작과 다르게 적힌 곳이 없는지 다시 확인한다.
> Google Play에 올린다면 이 문서를 누구나 열 수 있는 웹 주소(예: 공개 GitHub 저장소의 문서나 GitHub Pages)에 두고 그 주소를 Play Console과 앱 설정 화면에 넣는다(PDF·로그인 필요 페이지 불가).

시행일: 2026년 __월 __일
버전: 1.0

## 들어가며

"영민이"(이하 "앱")는 서울대학교 eTL(Canvas)을 쓰는 학생을 돕는 무료 오픈소스 안드로이드 앱입니다. 서울대학교가 만들거나 운영하는 공식 앱이 아닙니다.

앱을 만든 사람(박영민, 이하 "개발자")은 **서버를 운영하지 않으며, 이용자의 개인정보를 받아 보거나 보관하지 않습니다.** 앱이 다루는 정보는 모두 이용자의 휴대폰 안에 저장되고, 앱은 이용자가 연결한 서비스(서울대 eTL, 이용자 본인의 ChatGPT/OpenAI 계정 등)와 직접 통신합니다. 앱에는 광고, 분석(애널리틱스), 크래시 리포트 수집 도구가 들어 있지 않습니다.

이 방침은 앱이 휴대폰 안에서 어떤 정보를 어떻게 다루는지, 어떤 정보가 어디로 전송되는지를 알려 드리기 위한 것입니다.

## 1. 처리하는 정보와 목적

아래 정보는 모두 **이용자의 휴대폰 안(앱 전용 저장공간)**에만 저장됩니다. 개발자는 이 정보에 접근할 수 없습니다.

| 정보 | 언제 생기나 | 목적 | 저장 방식 |
|---|---|---|---|
| eTL 액세스 토큰 | 이용자가 첫 실행 안내나 설정에서 입력 | eTL에서 강의·과제·공지·성적·파일 정보를 불러오기 | Android Keystore 키로 암호화해 저장 |
| ChatGPT 로그인 정보(인증 토큰) | 이용자가 ChatGPT 계정으로 로그인 | AI 비서(OpenAI Codex)를 이용자 본인 계정으로 실행 | 앱 전용 저장공간의 Codex 설정 폴더(파일). 백업·기기 간 이전에서 빠짐(5항) |
| OpenAI API 키(선택) | 이용자가 고급 설정에서 직접 입력한 경우만 | 위와 같음(ChatGPT 로그인 대신) | Android Keystore 키로 암호화해 저장 |
| 대화 내용 | 이용자가 비서와 대화 | 대화 화면 표시, 이어서 대화하기 | 앱 전용 저장공간 |
| 비서 내부 대화 기록(Codex 세션 기록: 대화 전문과 비서가 불러온 eTL 정보) | 이용자가 비서와 대화 | 이전 대화 맥락을 이어 가기 | 앱 전용 저장공간의 Codex 설정 폴더. 대화를 지우면 함께 지움(4항) |
| 이용자가 첨부한 사진·파일 | 이용자가 대화에 첨부하거나 사진을 찍음 | 비서가 내용을 읽도록 | 앱 전용 저장공간(14일 뒤 자동 삭제) |
| eTL에서 받은 파일 | 이용자가 파일을 받거나 비서에게 읽기·요약을 요청 | 파일 제공, 비서가 읽기 | 앱 작업 폴더(14일 뒤 자동 삭제), 그리고 이용자가 원하면 휴대폰 `다운로드/etl` 폴더(이용자가 지울 때까지) |
| 비서가 만든 PDF(요약·정리본 등) | 이용자가 비서에게 PDF로 만들어 달라고 요청 | 이용자에게 결과물 제공 | 휴대폰 안에서 만들어(외부 변환 서버 없음) 휴대폰 `다운로드/etl/영민이가 만든 파일` 폴더에 저장(앱을 삭제해도 남음, 이용자가 지울 때까지)과 앱 작업 폴더(14일 뒤 자동 삭제) |
| eTL 정보 사본(과제·마감·제출 여부, 과목명, 공지 제목, 점수 변동 확인용 값, 과목별 강의자료 파일 목록) | 알림 확인·브리핑·"내 일정" 화면 | 마감·새 공지·새 과제·성적·제출 점검·새 강의자료 알림, 일정 화면, 위젯 | 앱 전용 저장공간 |
| 시간표(수업 시각·강의실), 보강·휴강 | 시간표 조회, 이용자 입력 | 시간표 화면, 수업 알림, 위젯 | 앱 전용 저장공간 |
| 내 마감(제목·메모·마감·알림 시각) | 이용자 입력, 또는 이용자가 요청해 비서가 입력 | 일정 화면, 알림 | 앱 전용 저장공간 |
| 캘린더로 내보낸 일정(과목명·과제명·마감 시각·eTL 과제 링크, 내 마감 제목·메모) | 이용자가 설정 → 캘린더에서 내보내기를 켰을 때만 | 휴대폰 캘린더 앱에서 마감 보기 | 이용자가 고른 휴대폰 캘린더(기본: 휴대폰 안에만 있는 "영민이" 캘린더). 앱은 어느 일정을 넣었는지만 앱 전용 저장공간에 기록 |
| 알림 기록 | 앱이 알림을 보낼 때 | 지난 알림 다시 보기 | 앱 전용 저장공간(90일·최대 300개) |
| 앱 설정(알림 시각, 방해 금지, 화면 모드, 모델 선택 등) | 이용자 선택 | 설정 유지 | 앱 전용 저장공간 |
| 동작 기록(진단 로그) | 앱 실행 중 | 오류 원인 확인 | 앱 전용 저장공간, 파일 1MB 두 개까지(넘으면 오래된 것부터 지움). 토큰·비밀번호·API 키는 남기지 않고, 로그인 주소의 인증 값과 로그인 코드는 가려서 남김 |
| 게시판(LearningX) 접속 토큰 | 이용자가 게시판 정보를 요청 | eTL 게시판 글 불러오기 | 메모리에만 두고 저장하지 않음 |

앱은 이름, 학번, 이메일, 전화번호, 위치, 연락처, 기기 식별자를 따로 수집하지 않습니다. 다만 eTL이나 OpenAI 응답 안에 이용자 이름 등이 들어 있을 수 있고, 그 내용은 위 표의 방식으로 휴대폰 안에만 남습니다.

## 2. 외부로 전송되는 정보

앱은 아래 경우에만 휴대폰 밖과 통신합니다. 모든 통신은 암호화(HTTPS)됩니다. 개발자의 서버를 거치지 않습니다.

| 받는 곳 | 보내는 정보 | 언제 |
|---|---|---|
| 서울대 eTL (myetl.snu.ac.kr) | eTL 액세스 토큰, 조회 요청 | 이용자가 비서에게 묻거나, 알림 확인·브리핑을 할 때. eTL 토큰은 이곳에만 보냅니다. 앱은 eTL에 글을 쓰거나 과제를 제출하지 않습니다(게시판을 열 때 eTL이 서명해 준 접속 요청 하나만 예외). |
| 서울대 수강편람 (sugang.snu.ac.kr), 서울대 파일 서버 (shine.snu.ac.kr) | 공개된 과목 코드, 강의계획서 첨부 요청 | 시간표·강의계획서를 불러올 때. 로그인이나 eTL 토큰은 보내지 않습니다. |
| OpenAI (이용자 본인의 ChatGPT 계정 또는 API 키) | 이용자의 질문, 첨부한 사진·파일, 비서가 이용자를 위해 eTL에서 불러온 정보(과목, 과제, 공지, 성적, 강의자료 내용, 내 마감, 시간표 등), 대화에 필요한 앱 지침 | 이용자가 비서와 대화할 때만(대화 화면이 열려 있을 때) |
| 이용자가 고른 캘린더 계정(예: Google, 삼성) | 캘린더로 내보낸 일정(1항) | 내보내기를 켜고 동기화되는 계정의 캘린더를 골랐을 때만. 앱이 직접 보내지 않고, 휴대폰의 캘린더 동기화가 그 계정 서버로 보냅니다. 기본 대상인 "영민이" 캘린더는 휴대폰 밖으로 나가지 않습니다. eTL 토큰이나 서명 링크는 일정에 넣지 않습니다. |
| GitHub (api.github.com) | 새 버전 확인 요청(개인정보·토큰·기기 정보 없음, 접속 IP는 GitHub에 전달됨) | 하루 한 번 이하. 설정 "업데이트 알림"에서 끌 수 있습니다. |

**Codex 사용 통계.** 앱은 Codex 설정에서 OpenAI로 보내는 사용 통계(analytics)·지표 내보내기·피드백 수집을 꺼 둡니다(`[analytics] enabled = false`, `[otel] metrics_exporter = "none"`, `[feedback] enabled = false`). 대화에 필요한 요청(질문과 비서의 도구 결과 등)은 위 표대로 OpenAI로 갑니다.

**OpenAI로 가는 정보에 대하여.** AI 비서는 OpenAI의 공식 Codex 프로그램을 휴대폰 안에서 실행하며, 이용자가 로그인한 **이용자 본인의 ChatGPT 계정(또는 API 키)**으로 OpenAI와 직접 통신합니다. 개발자는 이 대화를 보거나 받지 않습니다. OpenAI가 이 정보를 어떻게 처리·보관하는지는 OpenAI의 개인정보처리방침과 이용자 계정 설정(예: 데이터 학습 사용 여부)에 따릅니다: https://openai.com/policies/privacy-policy
OpenAI는 미국 등 국외에 있으므로, 대화를 하면 위 정보가 국외로 전송됩니다(이전받는 자: OpenAI, 이전 국가: 미국 등, 이전 시기·방법: 대화할 때마다 인터넷으로, 보유기간: OpenAI 방침과 이용자 계정 설정에 따름). 원하지 않으면 AI 비서를 쓰지 않고 알림·일정·시간표 기능만 쓸 수 있습니다.

**이용자가 직접 여는 링크.** 앱 안의 eTL 링크, 업데이트 받기, 문의(카카오톡 오픈채팅) 같은 버튼은 휴대폰의 브라우저나 해당 앱을 열 뿐이며, 그 뒤의 처리는 각 서비스의 방침에 따릅니다. 파일을 "공유"하거나 "다른 앱으로 열기"를 누르면 이용자가 고른 앱으로 그 파일이 전달됩니다.

## 3. 제3자 제공과 처리 위탁

개발자는 이용자의 정보를 제3자에게 제공하거나 판매하지 않으며, 처리를 위탁하지 않습니다. 2항의 전송은 모두 이용자가 앱 기능을 쓰기 위해 이용자 본인 계정이나 공개 서비스로 직접 보내는 것입니다.

## 4. 보유 기간과 파기

- 휴대폰 안의 정보는 이용자가 지우거나 앱을 삭제할 때까지 남습니다. 단, 첨부·작업 파일은 14일, 알림 기록은 90일(최대 300개)이 지나면 앱이 자동으로 지웁니다. 진단 로그는 파일 1MB 두 개를 넘으면 오래된 것부터 지웁니다.
- 지우는 방법
  - 대화: 대화 목록에서 지우기. 비서 내부 대화 기록(Codex 세션 기록)도 함께 지웁니다. 비서가 꺼져 있을 때 지운 대화는 기록 파일을 바로 지우고, 남은 내부 색인은 다음에 비서를 켤 때 지웁니다.
  - eTL 토큰: 설정 → eTL 토큰 → "eTL 연결 해제". 토큰과 함께 앱이 eTL에서 받아 둔 과제 목록, 새 과제·성적 비교 기준, 수강편람 시간표, 강의계획서 첨부, 새 강의자료 비교용 파일 목록을 지웁니다. 캘린더로 이미 내보낸 eTL 과제 일정은 지우지 않으므로, 지우려면 설정 → 캘린더에서 내보내기를 끄세요(앱이 넣은 일정만 지웁니다). 대화와 그 안에서 받은 파일, 알림 기록, 내 마감, 직접 넣은 수업·보강/휴강은 남으므로 필요하면 각각 지웁니다.
  - 알림 기록: 알림 기록 화면에서 지우기
  - ChatGPT 로그인: 설정에서 로그아웃
  - 내 마감, 보강·휴강: 해당 화면에서 지우기
  - 캘린더로 내보낸 일정: 설정 → 캘린더에서 내보내기 끄기(앱이 넣은 일정만 지움). 앱을 먼저 삭제하면 앱이 정리할 수 없으니 캘린더 앱에서 직접 지웁니다.
  - 휴대폰 `다운로드/etl` 폴더의 파일(비서가 만든 PDF가 있는 `다운로드/etl/영민이가 만든 파일` 포함): 파일 앱에서 직접 지우기(앱을 삭제해도 남습니다)
  - 전부: 휴대폰 설정 → 애플리케이션 → 영민이 → 저장공간 → 데이터 삭제, 또는 앱 삭제
- OpenAI에 이미 보낸 대화는 개발자가 지울 수 없습니다. ChatGPT/OpenAI 계정에서 관리하거나 OpenAI에 요청해야 합니다.
- eTL 토큰을 더 이상 쓰지 않으려면 eTL(계정 → 설정 → 승인된 통합)에서 그 토큰을 폐기할 수 있습니다.

## 5. 백업

앱은 Google 클라우드 백업과 기기 간 이전(새 휴대폰으로 옮기기, 예: 삼성 Smart Switch·Google 기기 이전)에서 앱 데이터를 하나도 내보내지 않도록 설정되어 있습니다. 그래서 새 휴대폰에서는 eTL 토큰 입력과 ChatGPT 로그인을 다시 해야 하고, 대화·내 마감·설정은 옮겨지지 않습니다.

## 6. 안전성 확보 조치

- eTL 토큰과 API 키는 Android Keystore로 암호화해 저장하고, 로그·오류 메시지에 남기지 않습니다.
- eTL 토큰은 서울대 eTL(myetl.snu.ac.kr)에만 보냅니다.
- 비서가 쓰는 eTL 도구는 휴대폰 안(127.0.0.1)에서만 열리고, 실행할 때마다 바뀌는 비밀값이 있어야 쓸 수 있습니다.
- 비서(Codex)의 인터넷 연결을 중계하는 휴대폰 안 프록시(127.0.0.1)도 앱을 켤 때마다 새로 만든 비밀번호가 있어야 쓸 수 있어, 휴대폰의 다른 앱이 이 앱을 거쳐 인터넷에 접속할 수 없습니다.
- 비서는 eTL을 읽기만 할 수 있고, 휴대폰 안의 "내 마감"과 보강·휴강만 바꿀 수 있습니다. 바꿀 때마다 대화에 표시됩니다.
- ChatGPT 계정에 연결된 다른 서비스(메일 등) 도구는 꺼 둡니다.
- 앱 소스 코드는 공개되어 있어 누구나 위 내용을 확인할 수 있습니다: https://github.com/manig235/ETLAssistant

## 7. 이용자의 권리

이용자는 언제든 4항의 방법으로 휴대폰 안의 정보를 보고, 고치고, 지울 수 있고, eTL 연결·ChatGPT 로그인·알림·업데이트 확인을 끌 수 있습니다. 개발자는 이용자 정보를 갖고 있지 않으므로 개발자에게 열람·삭제를 요청할 정보는 없습니다. OpenAI에 보낸 정보는 OpenAI에, eTL 정보는 서울대학교에 요청할 수 있습니다.

## 8. 권한

| 권한 | 이유 |
|---|---|
| 인터넷 | eTL, OpenAI, 수강편람, 업데이트 확인 |
| 알림 | 마감·공지·수업 알림 |
| 포그라운드 서비스 | AI 비서가 실행되는 동안 앱이 멈추지 않도록(알림으로 표시) |
| 부팅 후 실행 | 휴대폰을 다시 켠 뒤 알림 예약을 되살리기 |
| 캘린더 읽기·쓰기 | "캘린더로 내보내기"를 켤 때만 요청. 앱이 넣은 일정을 만들고 고치고 지우기(다른 일정은 건드리지 않음). "캘린더에 추가" 버튼은 권한 없이 캘린더 앱을 엽니다 |
| 배터리 최적화 예외 요청 | 앱을 닫아 두어도 알림 확인이 제때 돌도록(이용자가 허용할 때만) |

카메라, 위치, 연락처, 사진 전체 접근, 저장공간 전체 접근 권한은 쓰지 않습니다. 사진·파일은 이용자가 고른 것만, 사진 촬영은 휴대폰 카메라 앱을 통해 받습니다.
