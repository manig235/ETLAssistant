# 영민이 Windows 0.5.4

- 작업 표시줄·실행 파일·설치 및 제거 파일·바로가기에 영민이 로고를 적용했습니다.

- 압축을 직접 풀 필요 없는 설치 파일을 추가했습니다. 시작 메뉴·바탕화면에서 실행하고 Windows 설정에서 제거할 수 있습니다.
- 설치할 때 ‘Windows 로그인 시 자동 실행’을 선택할 수 있습니다. 앱의 연결 · 설정에서도 변경할 수 있습니다.
- 로그인 시 자동 실행은 대화창을 띄우지 않고 트레이에서 시작합니다. 펫 표시는 기존 설정을 따릅니다.
- 설치 버전도 기존 PC의 대화·설정·로그인 정보를 사용합니다. 프로그램 제거 후에도 사용자 데이터는 보존합니다.
- 앱 업데이트 안내는 설치 파일이 있는 버전에서 설치 파일을 우선 안내하며 기존 ZIP도 계속 제공합니다.

알림은 PC가 켜져 있고 로그인한 상태에서 앱이 실행 중일 때 동작합니다. ZIP을 내려받기만 해서는 시작 프로그램에 등록되지 않습니다.
