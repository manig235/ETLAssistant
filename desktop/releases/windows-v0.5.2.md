Windows x64용 영민이입니다. Android 앱과 함께 사용할 수 있으며 두 기기의 대화·자료는 자동 동기화되지 않습니다.

- 실행할 때와 6시간마다 GitHub의 새 Windows 버전을 확인합니다.
- 새 버전은 Windows 알림, 앱 안 배너와 알림 기록으로 알려줍니다. 변경 사항을 확인하고 GitHub에서 받을 수 있습니다.
- 같은 버전의 Windows 알림은 반복하지 않으며, 배너는 하루 미루거나 설정에서 새 버전 알림을 끌 수 있습니다.
- 프로젝트·병렬 세션·펫·시간표·성적 통계·반복 일정과 학습·파일 스킬을 포함합니다. 펫/트레이/설정에서 앱을 재시작할 수 있습니다.

**Windows 설치/실행:** `youngmin-windows-x64-v0.5.2.zip`을 받고 압축을 모두 푼 뒤 `YoungMini/YoungMini.exe`를 실행하세요. 업데이트할 때는 기존 영민이를 먼저 종료하세요. 대화·설정·로그인은 앱 폴더와 분리해 이 PC의 사용자 데이터 폴더에 보관합니다. Word·Excel·PowerPoint 원본 미리보기/검수에는 해당 Microsoft Office 설치가 필요합니다.

**Android 최신 버전 바로 받기:** https://github.com/manig235/ETLAssistant/releases/latest/download/youngmin.apk

이 Windows 릴리스는 Android의 ‘Latest’ 표시를 바꾸지 않습니다. ZIP의 SHA-256은 함께 올린 `.zip.sha256`에서 확인할 수 있습니다.
