## 학습·파일 스킬

PDF, Word, Excel/CSV, PowerPoint, 이미지, 데이터 분석·차트, 학습자료의 7종을 JAR에 넣고 `skill_list`/`skill_read`로 읽습니다. 실제 고정 도구에 맞춘 절차입니다. 원본 보존 수정, Office 출력, PDF 병합·추출·회전·양식·주석, 수식 계산·CSV·PNG 차트·이미지 변환·ICS를 지원합니다. 생성 PDF의 폴더 경계를 수정했고, Code-mode의 `image(part)`로 쪽 이미지가 모델 입력에 도달하는지 실제 Codex/로컬 모델 fixture로 검사합니다.

Office 원본 검수에는 해당 Microsoft Office 설치가 필요합니다. PowerPoint 사용 중/미설치/실패 시 검수 성공으로 보고하지 않습니다. Codex 호스트의 메일/클라우드/브라우저 커넥터, 임의 셸·Python, Word 변경 추적·댓글·편집 가능한 수식, Excel 매크로·네트워크 수식·네이티브 차트 편집기는 포함하지 않습니다. 생성형 이미지는 실제 계정의 도구 지원에 따릅니다. 모든 호스트 고급 기능을 복제했다고 안내하지 않습니다.
