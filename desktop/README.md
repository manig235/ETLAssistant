# 영민이 Windows 0.3.1

공식 Wanted Montage UI를 쓰는 Windows x64 학습 비서입니다. 서울대학교 공식 서비스가 아닙니다.

0.3.1은 시작 시 백엔드 응답보다 UI가 먼저 열리면 빈 화면이 되던 오류를 수정합니다. 초기 상태를 공유하고 오류 복구 화면을 추가했습니다. 말풍선을 중앙으로 정렬했습니다. 기존 대화·자료를 삭제하지 않습니다.

## 실행과 업데이트

`youngmin-windows-x64-v0.3.1.zip`을 **새 폴더에 모두 압축 해제**하고 `YoungMini/YoungMini.exe`를 실행합니다. Java·Node·Codex를 따로 설치하지 않습니다. 이전 버전은 트레이에서 완전히 종료한 뒤 새 버전을 실행하세요.

로그인·대화·다운로드는 `%LOCALAPPDATA%\YoungMini`를 계속 사용합니다. 이전 버전의 대화는 통합 프로젝트로 옮겨 읽고, 직접 담았던 파일도 카드로 복원합니다. 기존 데이터 폴더를 지울 필요가 없습니다.

첫 실행에는 **프로젝트 사용법 → 계정 연결 → 알림과 트레이 안내**가 나옵니다. 연결은 건너뛰고 나중에 **연결 · 설정**에서 할 수 있습니다. ChatGPT는 본인 계정의 Codex 이용 권한과 한도가 적용됩니다. 브라우저 로그인과 기기 코드를 지원합니다. eTL은 개인 액세스 토큰으로 연결합니다.

## 프로젝트와 대화

- 왼쪽 프로젝트·세션, 가운데 대화 하나, 필요할 때 오른쪽 파일 미리보기로 구성합니다.
- **통합 프로젝트**는 2026년 2학기 전체 과목을 기본 범위로 사용합니다. **과목 프로젝트**는 eTL의 26-2 과목마다 자동으로 생깁니다.
- 프로젝트 옆 `＋`로 **커스텀 프로젝트**를 만듭니다. 연결 과목은 여러 개 또는 없음으로 선택하고 공통 지침을 적습니다. 프로젝트 상단 `⋯`에서 지침을 수정합니다. 실행 중인 작업이 끝나면 해당 프로젝트 설정을 바꿀 수 있습니다.
- 같은 프로젝트의 자료 범위와 지침을 함께 쓰며 **각 세션의 대화 내용은 독립적**입니다. `새 대화`나 `세션 추가`로 대화를 늘립니다.
- 세션은 개수 제한 없이 백그라운드에서 병렬로 실행됩니다. 화면에는 선택한 대화 하나만 표시합니다. 프로젝트나 세션을 바꿔도 실행 중인 답변은 계속되고 결과는 원래 세션으로 돌아옵니다. 프로젝트로 돌아오면 그 실행 중 마지막으로 보던 세션을 엽니다.
- 모델과 **추론 강도(effort)**는 세션별로 저장합니다. 실제 모델이 지원하는 강도만 표시합니다.
- **Enter 전송**, **Ctrl+Enter / Shift+Enter 줄바꿈**입니다. 한글 조합 중 Enter는 전송하지 않습니다.
- 답변은 로컬 Markdown + KaTeX로 제목·강조·목록·표·코드·수식을 표시합니다. `$...$`, `$$...$$`, `\(...\)`, `\[...\]`를 지원합니다.

## 파일과 PDF

별도의 강의자료·파일 목록 탭은 없습니다. 채팅에서 “Ch4 강의자료를 받아 줘”, “기말 대비 문제를 PDF로 만들어 줘”처럼 요청합니다.

- **요청한 원본 자료와 완성된 결과 파일만** 채팅에 카드로 표시합니다. 답변을 만들며 참고용으로 받은 자료는 숨깁니다.
- PDF, PPTX, DOCX, XLSX, HWP/HWPX, 텍스트를 읽고, PDF 표·수식·스캔은 쪽 이미지로 확인합니다. 잠긴 파일과 동영상은 eTL에서 확인합니다.
- 파일 카드를 누르면 오른쪽 **미리보기 탭**이 열립니다. 여러 파일을 오가거나 닫을 수 있고, 모두 닫으면 대화가 넓어집니다. PDF는 쪽 이동·확대·텍스트 선택을 지원하고, 이미지·텍스트·지원 문서의 추출 텍스트도 보여줍니다. 원래 레이아웃이 필요한 Office/HWP 문서는 **외부 앱으로 열기**를 사용합니다.
- PDF 생성은 Markdown과 수식을 로컬 Chromium으로 A4 인쇄합니다. 도구로 만든 결과와 답변의 **PDF로 받기**가 같은 생성 경로를 사용합니다. **다른 이름으로 저장**으로 원하는 위치에 복사할 수 있습니다.

## 일정과 알림

왼쪽 **일정 · 알림**에서 개인 일정을 추가·수정·완료·삭제할 수 있습니다. 제목·한국 시간의 날짜와 시각·시험 여부·메모와 알림 시점(정각/10분 전/3시간 전/하루 전)을 지정합니다. 개인 일정에는 ChatGPT나 eTL 로그인이 필요 없습니다.

- eTL의 26-2 과제·시험 마감, 새 공지, 성적 등록과 **점수 변경**을 확인합니다. eTL 확인은 연결 직후 및 30분마다 진행하며 `지금 확인`으로 갱신할 수 있습니다.
- 공지·성적의 첫 조회는 조용히 기준만 저장합니다. 이후 새 공지와 이미 알고 있던 과제의 새 점수/변경 점수를 알립니다. 0점도 점수로 처리합니다. 확인하지 못한 과목의 기존 기준은 유지합니다.
- 미제출 과제는 3일/하루/3시간/10분 전 구간에서 마감을 알립니다. 여러 구간을 지나 다시 실행하면 가장 가까운 구간의 알림으로 합치고 중복을 막습니다.
- 일정·공지·성적은 Windows 알림으로 표시합니다. 완료된 대화와 PDF는 펫/앱에서 확인하고, 메인 창이 숨겨져 있으면 Windows 알림도 보냅니다. 받은 알림은 앱의 **알림** 목록에 남습니다.
- 종류별 알림과 펫은 설정에서 켜고 끌 수 있습니다. Windows 표시 여부는 설정의 **테스트 알림 보내기**로 확인합니다.

**창 닫기는 트레이로 접기**입니다. 펫·트레이가 살아 있는 동안 작업과 알림 확인을 계속합니다. **트레이 → 종료** 또는 **설정 → 영민이 종료**로 완전히 끝냅니다. PC가 꺼져 있거나 절전 중이면 제때 알릴 수 없으며, 다시 실행하면 놓친 일정을 확인합니다. Windows 시작 시 자동 실행하지 않습니다.

펫은 실행 중이거나 아직 읽지 않은 세션마다 **프로젝트 이름 + 세션 이름 + 작업 상태**를 말풍선으로 보여줍니다. 누르면 해당 세션으로 이동합니다. 말풍선과 내용은 펫 바로 위 중앙으로 정렬하며 꼬리를 표시합니다. 0.3.1 구현에는 모션이 없으며, 향후 모션을 추가할 계획입니다. 펫은 드래그로 옮기고, 말풍선이 많으면 스크롤합니다. 다른 앱의 대화·세션을 감시하지 않습니다.

## 데이터와 빌드

운영 서버 없이 동작합니다. 토큰은 Windows DPAPI로 암호화하고, 대화·자료·개인 일정·알림 기준은 이 PC에 보관합니다. 질문과 비서가 읽은 자료는 본인 ChatGPT 계정으로 OpenAI에 전송됩니다. PC와 휴대폰의 자동 동기화는 없습니다. 자세한 내용은 `PRIVACY.md`, 검증 결과는 `VALIDATION.md`를 확인하세요.

JDK 17, Node.js 22.13 이상, Python 3.11 이상이 필요하며 Android SDK는 필요 없습니다.

```powershell
.\gradlew.bat -p desktop test stageWindows
npm --prefix desktop/ui ci
npm --prefix desktop/ui run build
python desktop/scripts/package_windows.py
python desktop/scripts/verify_package.py desktop/dist/youngmin-windows-x64-v0.3.1.zip
```

Linux에서는 `./gradlew`를 사용합니다. 공식 Electron·Codex·code-mode host·Temurin JRE는 고정 SHA-256으로 검증합니다. 빌드가 업로드·게시를 수행하지 않습니다.

UI는 React + `@montage-ui/core`이며, Electron과 JVM은 전용 stdio 파이프로 통신합니다. 렌더러는 Node/파일 시스템에 직접 접근하지 않습니다. PDF 생성은 권한이 분리된 숨겨진 인쇄 창, 미리보기는 번들 PDF.js를 사용합니다. HTML·외부 스크립트·외부 이미지는 실행하지 않고 폰트·수식 라이브러리도 동봉합니다.

```powershell
npx --prefix desktop/ui playwright install chromium
npm --prefix desktop/ui test
```

실제 Codex 통합 검사는 `desktop/scripts/fetch_test_runtime.py`로 받은 바이너리를 `YOUNGMIN_TEST_CODEX`에 지정한 뒤 JVM 테스트를 실행합니다. 모델만 로컬 SSE 응답으로 대체하고 app-server → code-mode host → 인증된 MCP → 파일 읽기/PDF 생성·세션 라우팅·effort를 확인합니다. 사용자 계정·API 키·OpenAI 호출을 사용하지 않습니다.

`desktop/scripts/test_bridge.py --java <경로> --codex <경로>`는 실제 백엔드 파이프를 검사합니다. `desktop/ui/tests/electron-smoke.cjs`는 별도 임시 데이터와 실제 Electron/JVM/Codex를 실행해 주요 화면, 개인 일정, 한글·수식 PDF 생성부터 미리보기까지 검사합니다. Linux에서는 Xvfb와 `DISPLAY`를 지정하고, 개발용 `desktop/build/shell-dev/jre`, `lib`를 먼저 준비합니다. 패키지 검사는 `YOUNGMIN_DESKTOP_HOME`에 압축 해제한 `YoungMini`를 지정할 수 있습니다.

수동 GitHub Actions **Windows preview**는 Windows DPAPI를 포함한 테스트와 Windows ZIP 검증을 제공합니다. 이 작업에서 원격 CI를 실행하거나 릴리스를 게시하지 않았습니다.
