# 영민이 Windows 0.5.1

공식 Wanted Montage UI를 쓰는 Windows x64 학습 비서입니다. 서울대학교 공식 서비스가 아닙니다.

**[Windows 0.5.1 ZIP 바로 받기](https://github.com/manig235/ETLAssistant/releases/download/windows-v0.5.1/youngmin-windows-x64-v0.5.1.zip)** · **[Android 최신 APK 바로 받기](https://github.com/manig235/ETLAssistant/releases/latest/download/youngmin.apk)**

Windows ZIP을 모두 풀고 `YoungMini/YoungMini.exe`를 실행하세요. 업데이트할 때는 기존 앱을 먼저 종료합니다. 대화·설정은 이 PC의 사용자 데이터 폴더에 유지됩니다.

0.5.1부터 실행 시와 이후 6시간마다 GitHub의 새 Windows 버전을 확인합니다. Windows 알림·앱 배너·알림 기록에서 알리고, 변경 사항을 확인한 뒤 ZIP을 받을 수 있습니다. 같은 버전의 알림은 반복하지 않으며 배너는 하루 미루거나 설정의 ‘새 Windows 버전 알림’에서 끌 수 있습니다. 오프라인에서는 기존 확인 결과를 보존하고 조용히 재시도합니다. 설정의 수동 확인도 유지합니다.

Windows는 `windows-vX.Y.Z` 태그로 배포하고 GitHub의 Android ‘Latest’ 표시는 바꾸지 않습니다. 따라서 Android 최신 APK 바로 받기 주소는 버전이 올라가도 유지됩니다.

설정·트레이·펫 우클릭에서 **이름 재시작**을 선택할 수 있습니다. 진행 중 답변은 중단하며 저장된 세션·초안을 복원합니다. 대화창이 먹통이어도 트레이에서 사용합니다.

0.5.0은 Android 0.3.8의 Windows 공통 기능과 학습·파일 스킬 7종을 연결합니다. 시간표(수강편람/직접 수업/보강·휴강), 성적 통계, 반복 일정·회차별 완료/삭제, 공개 학습자료, 답변 복사·모델 자동 폴백, 말투·테마·세부 알림·과목별 표시·파일 정리가 추가됩니다. 사진과 PDF/Office/HWP/텍스트 문서를 입력할 수 있습니다. 로컬 일정/시간표/통계를 비서가 바꿀 때는 대화 안에서 변경 내용을 확인합니다. 홈과 프로젝트·병렬 세션·펫 배치는 유지합니다.

파일 스킬은 PDF, DOCX, XLSX/CSV, PPTX, 이미지, 데이터 분석/차트, 학습자료입니다. 실제 Office 파일 생성/읽기/수정과 원본 보존, PDF 병합·쪽 추출·회전·양식·주석, 수치 요약·차트 PNG, ICS 일정 파일 읽기/내보내기를 지원합니다. 모델이 `skill_list`/`skill_read`로 필요한 절차를 읽습니다. 스킬 문구만 복사해 호스트 전용 커넥터가 생긴 것으로 취급하지 않습니다.

**Office의 원본 레이아웃 검수와 미리보기에는 해당 Microsoft Office 설치가 필요합니다.** 설치되지 않아도 파일 생성/구조 읽기/편집은 되며 렌더링 실패는 구체적으로 표시합니다. PowerPoint가 이미 실행 중이면 사용자 발표를 보호하기 위해 원본 렌더링을 진행하지 않습니다. PDF 페이지 검수는 Office 없이 가능합니다. Word 변경 추적·댓글·편집 가능한 수식, 임의 Python/셸과 Codex 호스트 커넥터는 제공하지 않습니다. 생성형 이미지는 본인 계정의 실제 런타임 도구 지원에 따릅니다.

Windows 알림은 트레이에서 실행 중일 때 표시합니다. 첫 조회는 공지/점수/새 자료/과제 변경의 기준만 저장합니다. 방해 금지 시간에는 배너를 미뤄 기록을 보관합니다. PC 절전·종료 동안 정시 전달을 보장하지 않습니다. 휴대폰 CalendarProvider/위젯/공유 인텐트는 Windows API가 아니므로 홈·파일 첨부·ICS 파일 교환으로 대응합니다. 자동 동기화는 없습니다. 상세 대조는 `FEATURE_PARITY.md`를 확인하세요.

0.4.4는 세션 옆 이름 변경·삭제 버튼과 삭제 확인을 추가합니다. 대상 세션이 답변/PDF 작업 중이면 두 버튼을 잠급니다. 설정에 버그 신고 링크를 넣었고, 완성한 PDF를 다시 읽고 쪽 이미지로 검수할 수 있도록 생성 폴더 접근 오류를 고쳤습니다.

0.4.3은 홈 목록이 4개 이하일 때 내부 스크롤 없이 높이를 맞춥니다. 5개 이상은 기존처럼 목록을 스크롤합니다. 날짜 아래 일반 소개 문구를 제거하고 eTL 확인 시각은 유지합니다.

0.4.2는 상단 요약 카드 3개를 제거하고 마감/시험/오늘 할 일/새 공지를 구분선으로 나눈 2×2 홈으로 표시합니다. 좁은 창에서는 한 열로 이어집니다. 진행 중 대화는 아래에 유지합니다.

0.4.1은 홈의 항목 제목을 14→16px, 보조 날짜·설명을 12→14px, 카드 제목을 16→18px로 키웁니다.

0.3.4는 연결 · 설정 → 알림과 펫 → **펫 모션**에 Windows 설정 따르기 / 항상 켜기 / 끄기를 추가합니다. Windows가 움직임 줄이기를 요청하면 기본 모드에서는 펫이 멈춥니다. **항상 켜기**를 선택하면 OS 설정을 바꾸지 않고 펫만 움직이며 선택은 저장됩니다. 펫 우클릭 메뉴에서 앱을 완전히 종료할 수 있습니다. 비서 이름을 바꾸면 설정 창 제목과 우클릭 종료 메뉴도 같은 이름을 사용합니다.

0.3.3은 정지해 보이던 대기 모션을 더 알아보기 쉽게 키우고, 펫 창이 포커스를 받지 않아도 프레임을 계속 표시합니다. 펫을 끄거나 드래그하는 동안에는 모션을 멈춥니다. Windows 움직임 감소 설정은 유지합니다.

0.3.2는 상태별 펫 모션, 비서 이름 설정, 사진 첨부·썸네일, 대화별 랜덤 예시 질문과 선 아이콘을 추가합니다.

0.3.1은 시작 시 백엔드 응답보다 UI가 먼저 열리면 빈 화면이 되던 오류를 수정합니다. 초기 상태를 공유하고 오류 복구 화면을 추가했습니다. 말풍선을 중앙으로 정렬했습니다. 기존 대화·자료를 삭제하지 않습니다.

0.4.0은 홈 대시보드와 간단한 환영 화면, 서울대 로그인 기반 eTL 토큰 자동 발급을 추가합니다.

## 실행과 업데이트

`youngmin-windows-x64-v0.5.1.zip`을 **새 폴더에 모두 압축 해제**하고 `YoungMini/YoungMini.exe`를 실행합니다. Java·Node·Codex를 따로 설치하지 않습니다. 이전 버전은 트레이에서 완전히 종료한 뒤 새 버전을 실행하세요.

로그인·대화·다운로드는 `%LOCALAPPDATA%\YoungMini`를 계속 사용합니다. 이전 버전의 대화는 통합 프로젝트로 옮겨 읽고, 직접 담았던 파일도 카드로 복원합니다. 기존 데이터 폴더를 지울 필요가 없습니다.

첫 실행에는 **안녕하세요 영민이예요 → 계정 연결 → 알림 설정**이 나옵니다. 연결은 건너뛰고 나중에 **연결 · 설정**에서 할 수 있습니다. ChatGPT는 본인 계정의 Codex 이용 권한과 한도가 적용됩니다. 브라우저 로그인과 기기 코드를 지원합니다. eTL은 **서울대 로그인으로 연결**을 누르고 로그인 창에서 인증하면 토큰을 자동 발급·확인·저장합니다. **토큰 직접 붙여넣기**도 지원합니다.

## 홈

처음 열면 홈에서 **앞으로 7일의 다가오는 마감**, **최근 7일의 읽지 않은 공지**, **오늘 할 일**을 확인합니다. 시험 일정은 오른쪽 위에 따로 모읍니다. 시간은 한국 시간 기준입니다. 홈에서 개인 할 일을 추가하거나 완료 처리하고, 공지를 열면 읽음 상태가 저장됩니다. 첫 eTL 조회의 최근 공지는 홈에 표시하되 기존 공지를 Windows 알림으로 한꺼번에 보내지 않습니다.

왼쪽 프로젝트·세션을 누르면 기존 대화로 돌아갑니다. 홈으로 이동해도 작성 중 초안과 사진, 백그라운드 작업을 유지합니다. 펫의 세션 말풍선은 해당 대화를 바로 엽니다.

## 프로젝트와 대화

- 왼쪽 프로젝트·세션, 가운데 대화 하나, 필요할 때 오른쪽 파일 미리보기로 구성합니다.
- **통합 프로젝트**는 2026년 2학기 전체 과목을 기본 범위로 사용합니다. **과목 프로젝트**는 eTL의 26-2 과목마다 자동으로 생깁니다.
- 프로젝트 옆 `＋`로 **커스텀 프로젝트**를 만듭니다. 연결 과목은 여러 개 또는 없음으로 선택하고 공통 지침을 적습니다. 프로젝트 상단 `⋯`에서 지침을 수정합니다. 실행 중인 작업이 끝나면 해당 프로젝트 설정을 바꿀 수 있습니다.
- 같은 프로젝트의 자료 범위와 지침을 함께 쓰며 **각 세션의 대화 내용은 독립적**입니다. `새 대화`나 `세션 추가`로 대화를 늘립니다.
- 세션은 개수 제한 없이 백그라운드에서 병렬로 실행됩니다. 화면에는 선택한 대화 하나만 표시합니다. 프로젝트나 세션을 바꿔도 실행 중인 답변은 계속되고 결과는 원래 세션으로 돌아옵니다. 프로젝트로 돌아오면 그 실행 중 마지막으로 보던 세션을 엽니다.
- 모델과 **추론 강도(effort)**는 세션별로 저장합니다. 실제 모델이 지원하는 강도만 표시합니다.
- **Enter 전송**, **Ctrl+Enter / Shift+Enter 줄바꿈**입니다. 한글 조합 중 Enter는 전송하지 않습니다.
- 답변은 로컬 Markdown + KaTeX로 제목·강조·목록·표·코드·수식을 표시합니다. `$...$`, `$$...$$`, `\(...\)`, `\[...\]`를 지원합니다.

**비서 이름**은 연결 · 설정 맨 위에서 1~24자로 바꾸고 기본 이름으로 되돌릴 수 있습니다. 앱 안 이름, 대화 작성자, 펫 창과 메인 창 제목, 트레이 툴팁에 즉시 반영되며 재시작해도 유지합니다. 기본 데이터 폴더와 Windows 앱 식별자는 유지합니다.

새 대화의 예시는 여러 질문 중 **하나만 랜덤으로** 표시합니다. 같은 대화로 돌아와도 유지하며, 프로젝트에 연결한 과목 이름을 사용합니다. 누르면 입력창에 채우고 자동 전송하지 않습니다.

## 사진 첨부

입력창 아래 사진 아이콘으로 선택하거나, 입력창에 사진을 붙여넣기·드래그해 첨부합니다. PNG/JPG/WebP/GIF를 지원하며 한 번에 5장, 장당 20MB, 합계 50MB, 장당 2천만 화소 이하입니다. 앱은 PNG 사본으로 저장하며 GIF는 정지 사진으로 보냅니다. 지원하지 않는 HEIC 등은 PNG/JPG로 변환해 주세요.

사진은 **세션별 작성 중 첨부**로 보관하며, 전송 전에 미리 보거나 취소할 수 있습니다. 사진만 보내도 됩니다. 전송한 사진과 요청한 이미지 파일은 채팅에 썸네일로 표시하고, 누르면 기존 오른쪽 미리보기 탭에서 엽니다. 첨부 사진은 전송할 때 공식 Codex의 `localImage` 입력으로 전달합니다. 이미지 생성 모델·도구는 별도로 추가하지 않았습니다.

## 파일과 PDF

별도의 강의자료·파일 목록 탭은 없습니다. 채팅에서 “Ch4 강의자료를 받아 줘”, “기말 대비 문제를 PDF로 만들어 줘”처럼 요청합니다.

- **요청한 원본 자료와 완성된 결과 파일만** 채팅에 카드로 표시합니다. 답변을 만들며 참고용으로 받은 자료는 숨깁니다.
- PDF, PPTX, DOCX, XLSX, HWP/HWPX, 텍스트를 읽고, PDF 표·수식·스캔은 쪽 이미지로 확인합니다. 잠긴 파일과 동영상은 eTL에서 확인합니다.
- 파일 카드를 누르면 오른쪽 **미리보기 탭**이 열립니다. 여러 파일을 오가거나 닫을 수 있고, 모두 닫으면 대화가 넓어집니다. PDF는 쪽 이동·확대·텍스트 선택을 지원하고, 이미지·텍스트·지원 문서의 추출 텍스트도 보여줍니다. 원래 레이아웃이 필요한 Office/HWP 문서는 **외부 앱으로 열기**를 사용합니다.
- PDF 생성은 Markdown과 수식을 로컬 Chromium으로 A4 인쇄합니다. 도구로 만든 결과와 답변의 **PDF로 받기**가 같은 생성 경로를 사용합니다. **다른 이름으로 저장**으로 원하는 위치에 복사할 수 있습니다.

## 일정과 알림

왼쪽 **일정 · 알림**에서 개인 일정을 추가·수정·완료·삭제할 수 있습니다. 제목·한국 시간의 날짜와 시각·시험 여부·메모와 알림 시점(정각/10분 전/3시간 전/하루 전)을 지정합니다. 개인 일정에는 ChatGPT나 eTL 로그인이 필요 없습니다.

- eTL의 26-2 과제·시험 마감, 새 공지, 성적 등록과 **점수 변경**을 확인합니다. eTL 확인은 연결 직후 및 30분마다 진행하며 `지금 확인`으로 갱신할 수 있습니다.
- 공지·성적의 첫 조회는 조용히 기준만 저장합니다. 이후 새 공지와 이미 알고 있던 과제의 새 점수/변경 점수를 알립니다. 0점도 점수로 처리합니다. 확인하지 못한 과목의 기존 기준은 유지합니다.
- 미제출 과제는 3일/하루/3시간/10분 전 구간에서 마감을 알립니다. 여러 구간을 지나 다시 실행하면 가장 가까운 구간의 알림으로 합치고 중복을 막습니다.
- 일정·공지·성적은 Windows 알림으로 표시합니다. 완료된 대화와 PDF는 펫/앱에서 확인하고, 메인 창이 숨겨져 있으면 Windows 알림도 보냅니다. 받은 알림은 앱의 **알림** 목록에 남습니다.
- 종류별 알림과 펫은 설정에서 켜고 끌 수 있습니다. Windows 표시 여부는 설정의 **테스트 알림 보내기**로 확인합니다.

**창 닫기는 트레이로 접기**입니다. 펫·트레이가 살아 있는 동안 작업과 알림 확인을 계속합니다. **트레이 → 종료** 또는 **설정 → 영민이 종료**로 완전히 끝냅니다. PC가 꺼져 있거나 절전 중이면 제때 알릴 수 없으며, 다시 실행하면 놓친 일정을 확인합니다. Windows 시작 시 자동 실행하지 않습니다.

펫은 실행 중이거나 아직 읽지 않은 세션마다 **프로젝트 이름 + 세션 이름 + 작업 상태**를 말풍선으로 보여줍니다. 누르면 해당 세션으로 이동합니다. 말풍선과 내용은 펫 바로 위 중앙으로 정렬하며 꼬리를 표시합니다. 대기 중에는 숨쉬기·눈 깜빡임, 답변·PDF 작업 중에는 고개·팔 움직임, 새 작업 완료 때에는 1.5초 손인사를 보여줍니다. 초당 약 8개 포즈이며 말풍선과 클릭 영역은 움직이지 않습니다. 드래그 중에는 멈추고 Windows의 움직임 감소 설정을 따릅니다. 다른 작업이 실행 중이면 작업 모션이 우선이며, 실패·중단은 완료 손인사를 하지 않습니다. 펫은 드래그로 옮기고, 말풍선이 많으면 스크롤합니다. 다른 앱의 대화·세션을 감시하지 않습니다.

서울대 로그인은 앱 UI와 분리된 임시 창에서 사용자가 직접 진행합니다. 토큰 자동 발급은 고정 eTL 토큰 경로에만 POST하고 발급된 토큰을 확인한 뒤 백엔드로 전달해 저장합니다. 토큰은 90일 만료로 요청하며 만료 시 다시 연결합니다. 쿠키·로그인 창 저장소는 연결 완료/취소 시 지웁니다. 실제 서울대 계정 로그인은 아직 별도 확인이 필요합니다.

## 데이터와 빌드

운영 서버 없이 동작합니다. 토큰은 Windows DPAPI로 암호화하고, 대화·자료·개인 일정·알림 기준은 이 PC에 보관합니다. 질문과 비서가 읽은 자료는 본인 ChatGPT 계정으로 OpenAI에 전송됩니다. PC와 휴대폰의 자동 동기화는 없습니다. 자세한 내용은 `PRIVACY.md`, 검증 결과는 `VALIDATION.md`를 확인하세요.

JDK 17, Node.js 22.13 이상, Python 3.11 이상이 필요하며 Android SDK는 필요 없습니다.

```powershell
.\gradlew.bat -p desktop test stageWindows
npm --prefix desktop/ui ci
npm --prefix desktop/ui run build
python desktop/scripts/package_windows.py
python desktop/scripts/verify_package.py desktop/dist/youngmin-windows-x64-v0.5.1.zip
```

Linux에서는 `./gradlew`를 사용합니다. 공식 Electron·Codex·code-mode host·Temurin JRE는 고정 SHA-256으로 검증합니다. 빌드가 업로드·게시를 수행하지 않습니다.

UI는 React + `@montage-ui/core`이며, Electron과 JVM은 전용 stdio 파이프로 통신합니다. 렌더러는 Node/파일 시스템에 직접 접근하지 않습니다. PDF 생성은 권한이 분리된 숨겨진 인쇄 창, 미리보기는 번들 PDF.js를 사용합니다. HTML·외부 스크립트·외부 이미지는 실행하지 않고 폰트·수식 라이브러리도 동봉합니다.

```powershell
npx --prefix desktop/ui playwright install chromium
npm --prefix desktop/ui test
```

실제 Codex 통합 검사는 `desktop/scripts/fetch_test_runtime.py`로 받은 바이너리를 `YOUNGMIN_TEST_CODEX`에 지정한 뒤 JVM 테스트를 실행합니다. 모델만 로컬 SSE 응답으로 대체하고 app-server → code-mode host → 인증된 MCP → 파일 읽기/PDF 생성·세션 라우팅·effort를 확인합니다. 사용자 계정·API 키·OpenAI 호출을 사용하지 않습니다.

`desktop/scripts/test_bridge.py --java <경로> --codex <경로>`는 실제 백엔드 파이프를 검사합니다. `desktop/ui/tests/electron-smoke.cjs`는 별도 임시 데이터와 실제 Electron/JVM/Codex를 실행해 주요 화면, 개인 일정, 한글·수식 PDF 생성부터 미리보기까지 검사합니다. Linux에서는 Xvfb와 `DISPLAY`를 지정하고, 개발용 `desktop/build/shell-dev/jre`, `lib`를 먼저 준비합니다. 패키지 검사는 `YOUNGMIN_DESKTOP_HOME`에 압축 해제한 `YoungMini`를 지정할 수 있습니다.

수동 GitHub Actions **Windows preview**는 Windows DPAPI를 포함한 테스트와 Windows ZIP 검증을 제공합니다. 이 작업에서 원격 CI를 실행하거나 릴리스를 게시하지 않았습니다.

자동화 기본값과 다른 실제 OS 동작 검사는 `node desktop/ui/tests/native-motion.cjs`로 합니다. Playwright 없이 Electron을 직접 띄우고 실제 OS 미디어 조건에서 세 가지 모드와 대기/작업/완료 화면의 픽셀 변화를 검사합니다.
