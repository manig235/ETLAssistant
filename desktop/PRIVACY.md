# 영민이 Windows의 데이터 처리

영민이는 서울대학교 공식 서비스가 아닌 개인 프로젝트입니다. Windows 미리보기 0.5.1 기준입니다.

- 앱 운영 서버를 두지 않습니다. eTL 토큰, ChatGPT 로그인, 받은 자료, 대화는 이 PC에 보관합니다.
- **서울대 로그인으로 연결**은 비영구 격리 창에서 사용자가 직접 인증합니다. 로그인 비밀번호를 앱 코드가 읽거나 저장하지 않습니다. SNU HTTPS 도메인만 허용하고 고정 eTL 토큰 발급 경로에만 POST합니다. 자동 토큰은 90일 만료로 요청하며 학교 정책에 따라 더 짧아질 수 있습니다. 발급된 토큰은 쿠키 없이 확인한 뒤 로컬 백엔드의 DPAPI 저장소로 전달합니다. 임시 쿠키·캐시는 완료/취소/오류/시간 초과 때 정리합니다. 수동 토큰 붙여넣기도 지원합니다.
- eTL 토큰은 `myetl.snu.ac.kr`에만 인증으로 보냅니다. 첨부 파일의 외부 스토리지로 이동할 때 토큰을 보내지 않습니다. LearningX 게시판은 eTL 안의 LTI 인증과 읽기 요청만 사용합니다.
- ChatGPT 로그인은 `auth.openai.com`에서 처리합니다. Windows DPAPI로 로그인과 eTL 토큰을 암호화합니다. Codex에는 접근 토큰만 프로세스 간 표준 입출력으로 전달하며 갱신 토큰은 전달하지 않습니다.
- 사용자의 질문과 비서가 도구로 읽은 eTL 정보·파일 내용·PDF 쪽 이미지는 본인 ChatGPT 계정으로 OpenAI에 전송됩니다. 원본 파일을 다운로드한 것만으로 내용을 모델에 보내지는 않습니다. 비서는 요청에 답하기 위해 선택한 자료 외의 eTL 정보를 조회할 수도 있습니다.
- 직접 첨부한 사진은 앱 전용 `workspace/uploads`에 PNG 사본으로 보관합니다. 전송 전에는 로컬에만 저장하며, 전송하면 본인 ChatGPT 계정으로 OpenAI에 전달됩니다. 전송하지 않은 첨부를 취소하면 참조되지 않는 로컬 사본을 삭제합니다. 전송한 사진과 작성 중 첨부는 대화와 함께 로컬에 보관합니다. 비서 이름은 `appearance.json`에 저장합니다.
- 개인 일정, 알림 기록, 중복 방지 기준과 프로젝트 공통 지침도 로컬 JSON에 저장합니다. 공지·점수 변경 감지는 모델에 보내지 않고 eTL 응답을 로컬에서 비교합니다. 요청한 PDF 생성은 로컬 Chromium에서 처리합니다.
- 분석·광고 SDK, 앱 운영자에게 보내는 로그, 자동 업데이트 확인은 넣지 않았습니다. Codex의 선택적 분석·피드백 전송을 끕니다. OpenAI 서비스 자체의 처리는 해당 계정의 정책과 설정을 따릅니다.
- 화면은 공식 Montage와 로컬 Markdown/수식 뷰어로 구성합니다. 외부 스크립트·폰트·이미지를 불러오지 않고, 답변에 포함된 HTML·스크립트는 실행하지 않습니다. Electron UI는 샌드박스 안에서 동작하며, 인증·파일 처리는 로컬 백엔드와 전용 파이프로 주고받습니다.
- 채팅창을 닫아도 펫·트레이에서 실행이 유지됩니다. 완전히 종료하려면 트레이 또는 설정의 종료를 사용합니다. 다른 앱의 세션·로그인·브라우저 대화는 읽지 않습니다.
- 데이터는 `%LOCALAPPDATA%\YoungMini` 아래에 있습니다. 대화와 강의자료는 평문 파일이며 Windows 사용자 계정의 파일 접근 권한으로 보호됩니다. 토큰 암호화가 전체 대화 암호화를 뜻하지는 않습니다.
- ChatGPT 로그아웃은 저장된 ChatGPT 암호문과 실행 중 비서 세션을 제거합니다. eTL 연결 해제는 eTL 토큰과 메모리의 게시판 인증을 제거합니다. 대화·다운로드 파일·개인 일정은 남습니다. eTL의 알림 비교 기준과 캐시된 마감·공지 목록은 지웁니다. 모두 삭제하려면 앱을 완전히 종료한 뒤 위 데이터 폴더를 삭제합니다.
- 자동으로 기기 간 백업·동기화를 하지 않습니다. 사용자가 데이터 폴더를 클라우드 백업 대상으로 지정하면 해당 서비스로 복사될 수 있습니다.


## 0.5.0 학습·파일 작업

- 수업·성적 통계·반복 일정·브리핑·표시/알림 설정은 `school.json`/`agenda.json`에 저장합니다. 비서의 로컬 쓰기는 한 번의 구체적인 변경 내용에 대한 확인을 거치며, 취소/90초 시간 초과/대화 이탈/내용 변경은 적용하지 않습니다. eTL에는 쓰지 않습니다.
- 사용자가 선택한 사진과 문서는 `workspace/uploads`의 사본으로 보관합니다. 사진은 PNG로 정규화하며 문서는 형식·크기를 제한합니다. 질문에 첨부한 자료와 모델이 읽은 내용은 본인 OpenAI 계정으로 전달됩니다.
- MIT OCW의 공개 자료와 SNU 공개 수강편람에 조회할 수 있으며 eTL 토큰을 이 사이트에 보내지 않습니다. 공개 학습자료 검색은 설정에서 끌 수 있습니다.
- Word/Excel/PowerPoint 원본 렌더링은 외부 관계·매크로·활성 개체를 거부/제거한 로컬 임시 사본으로 설치된 Office를 호출합니다. 원본 파일을 덮어쓰지 않으며 앱이 임의 모델 코드를 실행하는 통로는 제공하지 않습니다. 새 작업 파일은 `workspace/generated`에 저장합니다.
- 파일 보관 기간은 기본 ‘자동 삭제 안 함’입니다. 기간을 선택해도 모든 대화의 자료/초안 참조와 사용자 PC의 별도 사본은 보호합니다. 참조 없는 앱 내부 파일만 정리합니다.
- Windows 업데이트는 기본 실행 시/6시간마다(설정에서 끄기 가능), 또는 수동으로 GitHub의 공개 배포 정보만 요청합니다. 계정·토큰·기기 식별자는 보내지 않습니다. 최근 확인/확인한 버전/하루 미루기는 windows-updates.json에 저장합니다. Android APK를 Windows 업데이트로 권하지 않습니다. 버그 신고는 카카오 오픈채팅 링크를 열며 앱이 메시지를 보내지 않습니다.
- ICS는 사용자가 직접 첨부/저장하는 일정 파일입니다. Windows/휴대폰/외부 캘린더 계정에 자동 접근하거나 동기화하지 않습니다.
